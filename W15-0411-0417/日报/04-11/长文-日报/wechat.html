01上游资源

AI 电力焦虑把小型核反应堆推上台前

4月10日，Meta、亚马逊、Google继续把长期协议和资金投向小型模块化反应堆，想给 AI 数据中心锁定更稳定的电源。

Meta已支持 Terrapower 690MW项目，并和 Oklo推进 1.2GW园区；亚马逊目标到 2039年上线 5GW，Google 盯的是 2030年首个项目。

INSIGHT

核电突然又热，不是情怀回潮，是电不够了。模型还在涨，数据中心先卡在变压器和批文。谁先拿到稳定电源，谁后面的算力成本就更稳。

02模型进展

阿里 Wan2.7 拿下视频编辑榜首

1334 Elo。DesignArena 最新视频编辑榜单里，阿里 Wan2.7排到榜首，领先第二名 Grok Imagine 1266分。

这套模型一周前刚发布，覆盖 文生视频、图生视频、参考生视频和视频编辑四个方向，想把 AI 从“出素材”推到“改成片”。

INSIGHT

视频模型这轮比的不是谁先出片，而是谁能进后期流程。榜单成绩当然重要，更关键的是阿里开始把控制力做成默认能力，这会直接碰到广告和短剧链路。

03政策监管

欧盟拟把 ChatGPT Search 按超大型搜索引擎监管

如果只看门槛，ChatGPT Search已经踩线了。OpenAI 披露，它在欧盟过去六个月平均月活约 1.204亿。

而 DSA把 4500万月活设为“超大型平台/搜索引擎”门槛。欧盟正在审阅数据，若定性成立，ChatGPT会被放进更严的透明度和风控框架。

INSIGHT

这条的量级不在罚款，在身份变化。搜索一旦被当成平台基础设施，OpenAI 后面每次功能扩张都要先过监管这一关，产品节奏会慢下来。

Anthropic 租下 CoreWeave 算力扩容 Claude

36氪 / Reuters · 04-11

Anthropic和 CoreWeave签了多年协议，算力会在今年晚些时候分阶段上线，专门给 Claude跑生产级负载。

路透称双方没披露金额，但 CoreWeave 说这笔合作能帮它继续摆脱对 微软的收入依赖；公司去年约 67%收入还来自微软。

💡 短评：这不是普通云采购，更像前沿模型厂在给自己补第二条命。只靠单一云厂太危险，谁能把算力来源做成组合，谁才扛得住爆量时刻。

微信支付把接入流程打包成 AI Skill

OSCHINA / GitHub · 04-11

微信支付这次把接入资料重新打包成 Skill 技能包 + AI友好文档 + AI友好 API，想让 IDE 里的 Agent 直接理解支付流程。

官方给的说法很直白：新商户可以让 AI 一键代写代码，常见能力覆盖小程序支付、退款、分账等 二十多项接口，接入时间从“天”压到“分钟”。

💡 短评：支付接入以前靠 SDK 和文档，现在开始变成“喂给 Agent 的工作说明书”。谁先把复杂接口翻成 AI 能执行的格式，谁就先吃到下一波开发流量。

06具身智能

百度智能云上线具身智能数据超市

4月10日，百度智能云联合多家机器人公司推出 具身智能数据超市 Beta，把任务语义、交互特性、环境条件做成可组合标签。

百度给出的背景数据也很 aggressive：2025年上半年它在中国具身 AI 云服务市场份额约 35%，服务过 30多家产业链企业。

INSIGHT

机器人现在最缺的不是 demo，而是可交易的数据。谁先把数据格式、标签和流转路径做成公共层，后面的模型和场景才有机会规模化复用。

07语音交互

豆包语音升级全双工模型，主打低时延抗打断

最近 豆包 APP把实时语音通话换成全双工模型 Seeduplex，重点打的是复杂环境下的抗干扰和动态判停。

雷峰网实测提到，餐厅、展会这类多人说话场景里，新版更不容易被旁人插话带偏；同时响应时延也降了，接龙和飞花令这类高频互动更顺。

INSIGHT

语音产品的分水岭，不在会不会说，而在会不会抢话。把打断和延迟压下去，AI 才可能从“演示功能”变成你真愿意开着用的入口。

Anthropic 用多代理 Harness 跑长时编程

InfoQ 中文站 · 04-11

Anthropic把长时编程拆成 规划、生成、评估三个代理，评估端还能用 Playwright MCP直接看页面效果。

InfoQ 引述其工程实践称，一次任务通常会跑 5到15轮，有时能拉到 4小时；关键做法是上下文重置和结构化交接，而不是死扛一个超长窗口。

💡 短评：Agent 写代码开始像流水线了。模型更强当然重要，但把“干活的”和“打分的”拆开，才是长任务不跑偏的真正工程手段。

MiniMax 开源 MMX-CLI 接入多模态 Agent

OSCHINA · 04-11

MiniMax开源了面向 Agent 的命令行工具 MMX-CLI，想让外部代理在命令行里直接调它的视频、语音、音乐和编程模型。

按官方说明，这套工具可以在 Claude Code、OpenClaw等环境里原生调用，不必单独适配接口，也不用再额外写一层 MCP Server。

💡 短评：模型公司现在不只卖模型，也开始抢 Agent 的默认调用位。谁把 CLI 做顺了，谁就更容易混进开发者日常工作流，后面的使用量会自己长。
