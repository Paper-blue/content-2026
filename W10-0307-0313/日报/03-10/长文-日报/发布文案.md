## 正文

1️⃣ Anthropic 起诉美国国防部
被列为“供应链风险”后直接起诉，30 多名 OpenAI 和 Google 员工联名声援。问题不只是一场官司，而是政府采购会不会用安全标签先筛人。

2️⃣ OpenAI 收购 Promptfoo
开源 LLM 测试平台，做红队测试和安全评估。Agent 要进关键业务，企业先看的已经不是会不会跑，而是出事前能不能测出来。

3️⃣ 微软推出 Copilot Cowork
多 Agent 在 Microsoft 365 内协同工作，从“一个 Copilot”升级为“一组 Copilot”。微软开始把办公室分工原样搬给 AI。

4️⃣ Anthropic 上线 Code Review
用多 Agent 系统审查 AI 生成的代码。代码生成越来越快后，真正稀缺的是“敢不敢上线”这道质检。

5️⃣ Nvidia 开源 NemoClaw
完整 Agent 框架，内置权限控制和审计日志。Nvidia 要的显然不只是框架份额，而是把开发者默认栈继续往自己硬件上带。

6️⃣ Karpathy 发布 autoresearch
把文献检索、实验设计、结果分析连成自动流程。以后研究岗位先被压缩的，很可能是执行层而不是想法层。

7️⃣ Claude 破解 Knuth 数学挑战集
这类题更像开放探索，不是按套路刷题。看点在于 AI 能不能在没有标准答案时继续组织证明路径。

8️⃣ OpenClaw 生态爆发
钉钉、飞书、企微先后原生集成，GitHub 星标突破 25,000。真正的分水岭不是 Star，而是平台愿不愿意把入口交出来。
