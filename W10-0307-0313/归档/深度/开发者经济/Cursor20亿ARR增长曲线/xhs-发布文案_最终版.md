# Cursor 20亿ARR，SaaS的增长公式被改写了

Cursor的年化收入刚突破20亿美元，3个月前还是10亿。从100万到20亿，不到30个月。

对比一下：Slack从100万到1亿花了3年，Cursor只用了12个月。Figma走到10亿用了8年，Cursor不到2年。

为什么这么快？因为Cursor的增长逻辑和传统SaaS完全不同。

传统SaaS靠团队采购驱动——要说服CTO、走审批流程、签年度合同。一个企业客户从接触到部署，通常3到6个月。

但Cursor的核心用户是个体开发者。下载到付费可能只要一个下午。免费转付费率36%，SaaS行业平均只有2%-5%。

更反常识的是：Cursor价格是GitHub Copilot的两倍，增长却更快。开发者不是在比价，是在比效率——省下的时间比订阅费值钱得多。

不过这种增长能不能持续，还有很大不确定性。微软在追赶，"vibe coding"可能让代码编辑器本身变得多余。

旧的增长曲线由组织画出，新的由个体画出。这条新曲线能陡多久，取决于"写代码"这件事还存在多久。
