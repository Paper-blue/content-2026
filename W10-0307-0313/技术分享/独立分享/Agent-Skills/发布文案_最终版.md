# Agent总忘事？13个Skill一次解决🔧

用Agent做复杂任务，聊到第20轮它开始忘前面说了什么。

不是模型变笨了。是context窗口塞满之后，注意力机制会退化。学术上叫"lost-in-the-middle"，中间的信息直接被忽略。

Agent Skills for Context Engineering，13.4K星的开源项目，把上下文管理拆成13个独立Skill。

底层讲注意力怎么衰减、怎么压缩。中间讲多Agent协调、记忆系统、工具接口。上层讲生产环境的评估和优化。

核心设计是渐进式披露。不是把所有指令一次性塞给Agent，而是按需加载——先读元数据，检测到任务再加载完整指令。类似操作系统的内存管理。

还有个反直觉的点：子Agent存在的意义不是模拟组织架构，是隔离上下文。每个Agent有独立的context窗口，互不污染。

平台无关，Claude Code、Cursor、自定义框架都能用。MIT开源，每个Skill控制在500行以内。

GitHub搜 Agent-Skills-for-Context-Engineering 就能找到。做Agent开发的话，值得花半小时读一遍。
