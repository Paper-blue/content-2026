# 开源AI伙伴，能语音能打游戏还能自托管🤖

你跟 AI 聊了一晚上，关掉窗口，它什么都不记得。想让它陪你打 Minecraft？它连方块都不认识。

AIRI 是一个开源的自托管 AI 伙伴，25.7K Stars。和普通聊天机器人不同，它能实时语音对话，能在 Minecraft 里帮你挖矿建房子，能在 Factorio 里用计算机视觉帮你规划产线。

浏览器打开就能用，不装东西。桌面版支持 CUDA 和 Metal 跑本地模型，不花 API 钱。手机也有，iOS 和 Android 都行。接入 20 多种 LLM，OpenAI、Claude、DeepSeek、Ollama 随便选。

它还能感知你的屏幕环境，知道你在写代码还是看视频。支持 Live2D 和 VRM 模型换形象，想拿来做虚拟主播也行。底层用 WebGPU 和 WebAssembly，3D 渲染和语音处理直接在浏览器里跑。

项目还在早期，坑不少，但 8000+ Discord 成员说明社区够活跃。适合想要一个真正"陪伴型"AI、而且愿意花半小时折腾的人。
