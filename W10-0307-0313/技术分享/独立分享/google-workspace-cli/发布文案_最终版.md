# 谷歌全家桶，终于能用命令行管了

Gmail、Drive、Calendar、Sheets、Docs、Chat、Admin，七个服务塞进一个命令行工具。

谷歌官方仓库出品，4.9K star，叫 Google Workspace CLI。

它不是写死命令让你背。启动时自动读取 Google Discovery Service，动态生成整个命令树。Google 加了新 API，你不用更新，下次跑自动就有。

一行 `gws drive files list` 列文件，一行 `gws gmail threads list` 查邮件。所有输出结构化 JSON，直接喂给脚本或 AI。

最有意思的是 MCP 支持。`gws mcp` 启动一个 MCP 服务器，Claude Desktop、Gemini CLI、VS Code 都能直接调用。100 多个 Agent Skills，50 个现成工作流配方。AI 不是读你屏幕，是直接操作你的 Google 数据。

坑也得说。OAuth 首次配置要建 Google Cloud 项目，手动审 85 个 scope，HN 上有人花了 45 分钟才跑通。配好之后一马平川，但第一次确实要有心理准备。

适合重度 Google 全家桶用户和 AI 工具链玩家。偶尔查邮件的，浏览器够了。

GitHub: googleworkspace/cli
npm install -g @googleworkspace/cli
