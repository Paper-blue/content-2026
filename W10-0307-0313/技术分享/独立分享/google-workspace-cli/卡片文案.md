## Google Workspace CLI

**一个命令行工具**，统管 Gmail、Drive、Calendar、Sheets、Docs、Chat、Admin。

**4.9K** ⭐️ 开源，谷歌官方仓库出品。

---

## 痛点在哪

每次处理 Google 全家桶，都要在浏览器里开一堆标签页。

收邮件一个页面，找文件一个页面，查日程又一个页面。想批量下载 Drive 里的文件？手动一个个点。想让 AI 帮你处理邮件？**没有统一接口**。

Web 界面是给人点的，不是给脚本跑的。

---

## 动态生成命令

`gws` 不是写死一堆命令等你用。

它启动时读取 Google 的 Discovery Service，**自动生成整个命令树**。Google 加了新 API，你不用更新工具，下次运行自动就有了。

`gws drive files list` 列文件，`gws gmail threads list` 查邮件，`gws calendar events list` 看日程。所有输出都是**结构化 JSON**，直接丢给脚本处理。

---

## AI Agent 原生支持

这可能是它最值得关注的设计。

`gws mcp` 一行命令启动 MCP 服务器，Claude Desktop、Gemini CLI、VS Code 都能直接调用你的 Google Workspace。**100+ Agent Skills**，50 个现成的工作流配方，覆盖邮件、文件、文档、表格、日历。

不是「AI 读你的屏幕」，是 AI **直接操作你的数据**。

---

## 认证和安全

支持 OAuth 登录、Service Account、多账号切换。

但说实话，**OAuth 设置是目前最大的坑**。HN 上不少开发者反馈，首次配置需要建 Google Cloud 项目、手动过 85 个 scope 审核，可能花 30-45 分钟。配好之后就顺了，但第一次确实有点折腾。

---

## 适合谁

重度依赖Google全家桶，想用命令行或AI agent批量操作——适合你。

偶尔查个邮件，浏览器够用了——不需要。

开发者和AI工具链玩家，值得花半小时配一下。

---

## 如何获取

GitHub: googleworkspace/cli

```
npm install -g @googleworkspace/cli
gws auth setup
```

Rust 用户: `cargo install --path .`

Apache-2.0 开源，注意：非谷歌官方支持产品。
