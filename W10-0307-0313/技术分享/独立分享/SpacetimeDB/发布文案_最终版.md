# 如果后端只剩一个数据库会怎样🤔

做多人在线游戏，后端要搭多少东西？服务器、数据库、消息队列、状态同步……小团队光把架构跑通就要几个月。

SpacetimeDB 把这些全砍了。

1️⃣ 它是一个数据库，也是服务器。GitHub 22.2K 星，Clockwork Labs 做的，a16z 和 Supercell 投的钱。

核心思路：业务逻辑直接写在数据库里运行，客户端直连数据库，中间不需要 Web 服务器。

2️⃣ 你把代码编译成 WebAssembly 上传到数据库，它叫 Module。所有数据跑在内存里，Rust 模块实测每秒 15 万笔事务，是 Node.js + PostgreSQL 的 3 倍。

客户端订阅数据变更，数据库自动推送。TypeScript、C#、Rust 都能写，不用自己造同步轮子。

3️⃣ Clockwork Labs 自己用它做了 BitCraft Online，一整个 MMORPG 的后端就是一个 Module。聊天、物品、地形、玩家位置，全在数据库里处理完再同步给客户端。没有微服务，没有 K8s。

有人用 Claude Code 加 SpacetimeDB，30 分钟做出了 agar.io 风格多人游戏，从写代码到部署上线。

4️⃣ 安装就一行命令：
curl -sSf https://install.spacetimedb.com | sh

然后 spacetime init --lang typescript 初始化项目就能跑。有托管平台 Maincloud 可以跳过运维，也可以自己 Docker 部署。需要会一门编程语言。

做实时多人应用的开发者可以花 10 分钟跑个 quickstart，差别在架构层面，省的是搭后端那几个月。
