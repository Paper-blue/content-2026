# 字节开源SuperAgent，调研自动跑🔍

写一份行业报告，搜20个网页，读5篇论文，整理成文。手动做完，4个小时没了。

字节跳动开源了DeerFlow，一个SuperAgent框架，24.5K Stars。

它的思路不是让一个AI干所有事，而是拆成多个智能体并行跑。一个搜索，一个阅读原文，一个写报告，互不干扰。你提一个问题，背后可能5个智能体同时在工作。

不只是文字研究。它内置Docker沙箱，智能体可以直接写Python跑数据分析。比如分析比特币价格波动，它自己写爬虫抓数据、画图表、写结论。代码在隔离容器里跑，不碰你本地环境。

输出也不只是一段文字。能生成结构化Markdown报告，一键转PPT，甚至生成播客音频把报告读给你听。从调研到交付，全链路自动化。

适合经常做行业调研、竞品分析、技术选型的人。每周花几小时整理资料的，能省一大半时间。不适合简单问答，这是重型框架，配置需要Python环境和Docker。

想试的话，终端输入：
git clone https://github.com/bytedance/deer-flow.git
然后 make docker-init && make docker-start
大概15分钟能跑起来。
