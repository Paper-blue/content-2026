## 为什么要拆开看

用 Claude Code 写代码，它能读文件、跑命令、自己规划任务。

但它到底怎么工作的？

源码几万行，看不动。这个项目把**核心机制拆成12节课**，每节一个可运行的 Python 文件，从最简单的循环开始，逐步搭出一个完整的 Agent。

---

## 核心：一个循环搞定一切

第一课就揭底牌。

用户输入 → 发给大模型 → 模型决定调什么工具 → 执行工具 → 把结果塞回对话 → 再问模型 → 循环，直到任务完成。

这就是所有 AI 编程 Agent 的骨架。**Bash is all you need**，一个终端加一个循环，就能跑起来。

后面 11 课，都是在这个骨架上加零件。

---

## 12课拆出什么

**第1-3课**：Agent循环 + 工具调用 + 任务规划。最小可用 Agent，能读文件能跑命令还能给自己列 todo。

**第4-6课**：子Agent + Skills加载 + 上下文压缩。大任务拆小任务，按需加载知识文档，对话太长时自动摘要腾空间。

**第7-12课**：后台任务 + 多Agent协作 + 自治团队。多个Agent各自领任务、互相通信、在独立目录里干活互不干扰。

从单兵到团队，**每课只加一个机制**，不跳步。

## 谁适合学

适合：对 Agent 原理好奇的开发者，用过 Claude Code 或 Cursor 想知道背后逻辑的人，准备自己搭 Agent 工具链的团队。

不适合：纯零基础（需要会基本的 Python），或者只想用工具不关心原理的人。

需要 **Python 环境 + Anthropic API Key**。每节课几百行代码，跟着跑大概 **2-3小时** 能过一遍核心课程。
