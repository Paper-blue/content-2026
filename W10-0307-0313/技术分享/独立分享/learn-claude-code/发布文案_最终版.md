# 21K Star开源课程，12节课拆透Agent原理🔧

用 Claude Code 写代码，它能读文件、跑命令、自己规划任务。

但它到底怎么做到的？

源码几万行看不动。shareAI-lab 的这个开源项目，把 AI Agent 的核心机制拆成了12节课。每节一个 Python 文件，从最基础的循环开始，一步步搭出一个能用的迷你 Claude Code。

第一课就揭底牌：用户输入发给模型，模型决定调什么工具，执行完把结果塞回对话，再问模型。循环，直到任务完成。所有 AI 编程 Agent 的骨架，就这一个循环。

后面11课逐步加零件。子Agent拆分大任务，Skills按需加载知识，上下文太长自动压缩。到最后几课，多个Agent各自领任务、互相通信，在独立目录里干活互不干扰。

21.4K Stars，4.2K Forks，中英日三语文档，配套交互式可视化平台。MIT协议免费开源。

需要 Python 环境和 Anthropic API Key，有基础编程经验就行。每节课几百行代码，跟着跑 2-3 小时能过完核心内容。

想试的话，GitHub 搜 shareAI-lab/learn-claude-code，clone 下来第一节直接跑。
