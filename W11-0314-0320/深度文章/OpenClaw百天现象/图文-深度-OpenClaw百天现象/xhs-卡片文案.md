---
title: '免费的东西最贵'
description: 'OpenClaw用100天锁死了整条AI工具链'
---

有些开源项目看着是在长 Star。

但 OpenClaw 这波更像是在抢位置。

它从冒头到被百度、飞书、钉钉、企微接进产品，中间只隔了三个月。

**最可怕的地方是，它还是免费的。**

---

## 不是爆火

30万 GitHub Stars，60天。

这当然够夸张。

但真正该盯着看的，不是它火得多快。

而是它为什么能这么快进平台。

---

## 平台在干嘛

百度先动了。

DuClaw 直接进百度 App，背后是 **7亿月活** 的入口。

飞书和钉钉也不是做个插件试试水。

它们是把 OpenClaw 的 skill 协议，直接塞进自己的消息系统里。

企微更直接，几乎把 skill marketplace 映射成企业应用商店的一部分。

---

## 锁的不是代码

OpenClaw 用的是 MIT 协议。

代码是开的。

可它卡住的根本不是代码，而是 **生态位**。

等几个主平台都吃下同一套 skill 协议，开发者写一次，就能到处跑。

ClawHub 现在已经堆出了 **15万个公开 skill**。

---

## 免费不代表便宜

很多人先被“免费开源”打动。

但 OpenClaw 真正贵的，不在 license。

而在后面的 Token 账单。

一个“帮我整理会议纪要”，背后可能已经触发 **十几个 skill**。

有人一个月直接跑出 **$3,600**。

单次 Agent 调用的 Token 消耗，是传统 API 的 **1000倍**。

---

## 更麻烦的是安全

2026年2月，OpenClaw 核心协议层挖出 **CVSS 8.8 高危漏洞**。

ClawHub 上还有 **1000多个恶意 skill**。

npm 的恶意包，大多脏的是开发环境。

OpenClaw 的恶意 skill，脏的是生产环境里的 Agent 行为。

**如果是你，你更担心成本，还是更担心安全？**
