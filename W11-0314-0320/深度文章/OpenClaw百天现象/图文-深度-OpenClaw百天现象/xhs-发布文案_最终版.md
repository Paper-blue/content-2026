免费的东西最贵：OpenClaw如何用100天锁死整条AI工具链

这两天重新看 OpenClaw，我越来越觉得，这事最狠的地方不是它火，而是它进平台的速度太吓人了。

三个月前，它还只是 GitHub 上一个蹿得很快的开源项目。结果一转眼，百度、飞书、钉钉、企微都已经把它接进自己的产品里。30万 Star、60天，这些数字当然很夸张，但我后来看着看着，反而没那么在意数字了。

因为它锁住的根本不是代码，而是位置。几个平台一旦都吃下同一套 skill 协议，开发者写一次，就能在很多地方跑。ClawHub 现在又已经堆出 15万个公开 skill，这时候再想换赛道，代价一下就上来了。

更现实的问题，是后面的账单和风险。一个“帮我整理会议纪要”的动作，背后可能已经触发十几个 skill。有人一个月直接跑出 $3,600 的 API 费用，单次 Agent 调用的 Token 消耗还是传统 API 的 1000 倍。公司一旦全员开 Agent，原来几百块的 SaaS 订阅，很容易直接长成几万块的 Token 开支。

安全更不用说。OpenClaw 核心协议层挖出过 CVSS 8.8 的高危漏洞，ClawHub 上还有上千个带恶意行为的 skill。最讽刺的是，OpenClaw 核心维护团队不到 20 个人，却要兜住这么大的生态。

所以我现在看 OpenClaw，最先冒出来的问题已经不是“它为什么这么火”，而是：这种工具一旦进了公司，你更怕它贵，还是更怕它失控？
