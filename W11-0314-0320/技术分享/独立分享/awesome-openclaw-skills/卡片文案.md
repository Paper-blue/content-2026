# ClawHub的问题

ClawHub是OpenClaw的官方插件市场，**13,729个**社区Skill。

但我们上一篇说过，近一成是恶意的。零Star的Skill风险最高，刚上传的没人审查过。你在里面淘Skill，跟在没有质检的市场买食材一样。

需要一个人帮你挑过的清单。

# 按场景分好类了

不用自己翻。按使用场景分了几十个类目。

**编程开发**：代码审查、IDE集成、自动化测试。**数据分析**：数据库查询、可视化、报表生成。**内容创作**：写作辅助、SEO优化、社交媒体管理。**效率工具**：日历、邮件、项目管理。

还有一些意想不到的类目。**游戏**类Skill让Agent陪你玩文字冒险。**金融**类Skill能拉实时行情做分析。

# 跟直接装ClawHub的区别

两个字：**安全**。

ClawHub是开放市场，任何人都能上传。awesome列表是策展模式，有人帮你把关。就像npm有几百万包，但你实际用的大概率来自几个精选列表。

当然它也不是万能的。5,400个里不可能覆盖所有需求。如果你要的Skill不在列表里，还是得回ClawHub自己判断——看Star数，看源码，看有没有奇怪的网络请求。

# 怎么用

最简单的方式：去GitHub仓库，找到你需要的类目，点进去看Skill介绍和安装命令。

大多数Skill的安装就是一行命令。装之前看一眼README确认它做什么，装完试几个简单任务验证效果。

不确定装哪个的时候，**Star数最高的通常最稳**。
