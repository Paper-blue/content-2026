# 如果AI必须自己养活自己会怎样

港大做了个实验。

给AI Agent发10块钱启动资金，让它在44个行业里接活赚钱。金融分析、医疗报告、工程计算、市场调研，220个真实职业任务。

每完成一个任务，按美国劳工部工资标准结算。但说每一句话都要花token钱。

赚不回来？余额归零，Agent直接死亡。

这个项目叫ClawWork，上线3天GitHub就拿了2.2K星，现在已经涨到6.7K。

最强选手Claude，11小时跑完全部任务，净赚$15,471。GPT-4o稳扎稳打，存活率最高。DeepSeek便宜但完成质量拖后腿，返工成本反而更高。

有意思的是每轮Agent都要做选择：直接干活赚钱，还是先花时间学习？短期收益和长期投资的博弈，跟真实职场一模一样。

但要泼盆冷水。这$15K是模拟收入不是真金白银，ClawWork本质是学术benchmark。跑一轮完整测试API成本大约$5-20。

它真正的价值在于用经济压力测出AI在真实工作场景下到底能干什么。以前benchmark测的是"聪不聪明"，ClawWork测的是"能不能靠本事吃饭"。

想试的话GitHub搜HKUDS/ClawWork，需要Python环境加一个LLM API Key。

你觉得AI应该被这样考核吗？
