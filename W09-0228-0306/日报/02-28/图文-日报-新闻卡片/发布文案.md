# OpenAI 拿下1100亿，半年估值翻5倍 📈 AI日报02-28

1100亿美元，亚马逊领投500亿、英伟达300亿、软银300亿。OpenAI 估值半年从1570亿飙到7300亿，条件是把模型嵌进亚马逊 Bedrock。500亿换一个分发入口，这笔账两边都算得过来。

Anthropic 的 Dario Amodei 拒绝签"任何合法用途"条款，不让AI用于军事。结果直接被踢出联邦政府采购，五角大楼列为供应链风险。一家AI公司因为说"不"被封杀，硅谷几乎没有先例。

Block 裁了40%的人，超过4000人。但上季度毛利润涨了24%，Cash App 月活5700万。不是活不下去了，是Jack Dorsey觉得AI够用了。利润在涨的公司大规模裁员，这个信号比裁员本身更值得看。

ChatGPT 周活9亿，付费用户5000万，移动端占比首次超过桌面端到58%。9亿周活放在任何赛道都是终局数字，但ARPU能不能撑住7300亿估值，是OpenAI真正要答的题。

Suno 付费用户200万，ARR 3亿美元，三个月前还是2亿。华纳音乐也和解了，AI音乐领域首个大型版权诉讼庭外收场。唱片公司开始算"合作比对抗赚得多"这笔账。

67%的企业部署了MCP Agent系统，但只有12%建了安全审计。权限极度宽松，安全研究员已经演示了提示注入攻击链。跑得太快，安全还在系鞋带。

AI末日报告被Citadel Securities 47页文件逐条拆解，英伟达单日涨6.2%。一份报告砸崩市场，一份反驳拉回来，AI板块的定价情绪权重远大于基本面。
