## 遇到的问题

### 1. Chrome 多标签页崩溃（严重）

**现象**：连续打开 7+ 标签页后，Chrome 进程崩溃（EXC_BREAKPOINT/SIGTRAP），重启也失败。

**根因**：Chrome 144 在 macOS 26.3 上，多标签页崩溃后 Session Storage 数据损坏，导致启动时立即 crash。

**修复**：清理 profile/Default/ 下的 Session Storage、Sessions、Code Cache、Service Worker 等目录。已集成到 `start-browser.py` 的 3 阶段崩溃恢复流程。

**改善**：
- 统一浏览器启动脚本 `start-browser.py`，内置自动清理崩溃残留
- 3 阶段恢复：正常启动 → 清理 session 缓存 → 禁用扩展

### 2. 标题字数超限未预检

**现象**：多篇文章标题超过抖音 20 字限制，需要临时用 `--title` 参数覆盖。

**根因**：没有在运行脚本前统一预检所有标题字数。

**改善**：
- 标准发布流程 Step 1 强制标题预检
- 已写入 SKILL.md 的「标准单篇发布流程」

### 3. 合集「深读AI」未找到

**现象**：脚本报 `⚠️ 合集「深读AI」未找到`。

**可能原因**：合集列表加载延迟，或 Semi Select 下拉未完全展开。

**改善**：
- MCP Snapshot 验证时应检查合集状态
- 如合集缺失，通过 MCP 手动补选

### 4. 抖音 tag 限制 5 个

**现象**：用户反馈抖音只支持 5 个 tag，之前输入了过多 tag。

**修复**：`douyin-upload.js` 已加 `topics.slice(0, 5)` 限制，超出会 warn。

### 5. 未执行 MCP Snapshot 验证和点击发布

**现象**：脚本 `--no-submit` 完成后直接报告结果，没有走 MCP snapshot → 验证 → 点击发布的完整流程。

**根因**：标准发布流程未写入 skill，Agent 使用了简化流程。

**改善**：
- 已将 5 步标准发布流程写入 SKILL.md
- Step 3 MCP Snapshot 验证 + Step 5 MCP 点击发布

## 流程改善总结

| 改善项 | 改前 | 改后 |
|--------|------|------|
| 浏览器启动 | 3 个独立脚本 | 统一 `start-browser.py`，含崩溃恢复 |
| 标题预检 | 无，脚本运行时才报错 | Step 1 强制预检，提前准备 --title |
| 上传验证 | 无，信任脚本输出 | Step 3 MCP Snapshot 验证 |
| 发布方式 | --no-submit，用户手动 | Step 5 MCP 点击发布（验证后） |
| Tag 限制 | 无限制 | 脚本强制 slice(0, 5) |
| 发布记录 | 无 | 每次创建临时记录文档 |
