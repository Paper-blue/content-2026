# 终端AI编程搭档 改完代码自动提交

你在终端里改bug，打开浏览器把代码贴给ChatGPT，等回复，再贴回来。三个文件改下来，来回六次。

Aider直接住在你的终端里。说一句"把这个函数的错误处理加上"，它改好文件、保存、自动commit。不用复制粘贴，不用切窗口。

41K Stars的开源项目，核心能力是代码库地图。它会扫描整个项目的文件依赖和函数结构，改一个文件时知道关联的其他文件该怎么动。跟网页版AI聊天最大的区别就在这——它理解你的项目，不是只看你贴的那段代码。

模型随便切。Claude Sonnet、GPT-4o、DeepSeek、本地模型，换一个参数的事。API Key是你自己的，用多少付多少，工具本身免费。

Git集成是真的深。每次改完自动生成语义化的commit message，不满意git undo回退，想看改了什么git diff照常用。不是另起炉灶，是融进你现有的工作流。

适合常驻终端的开发者，远程服务器、命令行工作流、不想为IDE付月费的人。需要Python环境和一个LLM的API Key，装好大概10分钟。

不适合完全不用命令行的人，那种情况Cursor体验更好。

GitHub: github.com/Aider-AI/aider
安装：pip install aider-install && aider-install
