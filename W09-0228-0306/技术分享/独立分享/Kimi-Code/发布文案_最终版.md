# 国产开源编程Agent 终端里的AI搭子

用 Claude Code 写代码，体验是好，但每月 API 费用几百块，国内网络访问也不太方便。

月之暗面开源了 Kimi Code CLI，一行 pip install 装进终端，直接用。

背后是 K2.5 模型，1万亿参数，SWE-Bench 76.8%，和 Claude 同一梯队。能读代码、跑命令、自己拆任务执行，不是补全工具，是自主规划的 Agent。

支持 VSCode、Cursor、Zed 集成，Ctrl-X 切 Shell 模式，MCP 协议接外部工具。截图丢给它能直接生成代码，UI 还原度实测超 90%。

价格差距很明显。同样的任务 Claude 花 5 块，Kimi 大概 1 块。月卡 49 元，国内直连不用代理。

说几个坑：速度比 Claude Code 慢，复杂任务偶尔结果不一致，生成的 UI 有点 PPT 感。适合写逻辑，精细设计还得靠别的。

如果你在国内做开发，想要一个便宜稳定的终端 Agent，值得花 5 分钟试试。追求极致编码体验的话，Claude Code 目前还是领先。
