## 封面

Kimi Code

月之暗面开源的**终端编程 Agent**

基于 Kimi K2.5，**6.9K** GitHub Star

---

## 现在的AI编程，有点贵

用 Claude Code 写项目，体验确实好。

但每个月光 API 费用就要**几百块**，国内访问还得折腾代理，动不动封号。

想找个**稳定、便宜、国内能直连**的替代方案，翻遍 GitHub 也没几个能打的。

---

## 月之暗面的回答

Kimi Code CLI，一行命令装进终端。

它能**读你的代码、跑 shell 命令、自己拆解任务**一步步执行。不是补全工具，是一个能自主规划的编程 Agent。

背后是 **1 万亿参数**的 K2.5 模型，MoE 架构，384 个专家模块。SWE-Bench 跑到 **76.8%**，和 Claude 同一梯队。

---

## 不只是终端工具

支持 **VSCode、Cursor、Zed** 三大编辑器集成。

按 `Ctrl-X` 直接切换 Shell 模式，不用退出对话就能跑命令。支持 **MCP 协议**，能接外部工具链。

最狠的是**多模态输入**——截图丢给它，能直接根据界面生成代码。极客公园实测，UI 还原度超过 **90%**。

---

## 价格是真的香

K2.5 的 API 定价：输入 **$0.60**/百万 token，输出 **$2.00**/百万 token。

同样的编程任务，Claude 要花 5 块钱，Kimi 大概 **1 块钱**。一个迭代任务低至**5毛**。

月卡 **49 元**，比 Claude Code 便宜一个量级。国内直连，不用代理，不怕封号。

---

## 诚实说几个坑

速度比 Claude Code 慢，复杂任务**要等**。

同样的 Prompt 跑两次，偶尔结果**不一致**——Agent 的执行可靠性还在打磨。

审美能力一般，生成的 UI 有点"**PPT 感**"。适合写逻辑，不适合做精细设计。

---

## 谁适合用

适合你，如果：你在国内做开发，需要一个**便宜稳定**的终端编程 Agent，能接受早期项目的粗糙。

不适合，如果：你追求极致的编码体验和可靠性，Claude Code 的质量目前还是领先的。

用 Claude Code 觉得贵的开发者，值得花 **5 分钟**试一下。
