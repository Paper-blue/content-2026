## HuggingFace Skills

给你的 AI Agent 装上**机器学习技能包**。

**7.2K Star** 的开源项目，**HuggingFace 官方**出品。

---

## 痛点在哪

你让 Claude Code 帮你**微调一个模型**。

它开始写训练脚本，选错了 GPU 型号，数据集格式也没验证，跑了**半小时报错**——从头来过。

换一个 Agent，比如 Codex，同样的坑再踩一遍。每个 Agent 都像个没经验的实习生，**有能力但缺知识**。

---

## 标准化的技能定义

HuggingFace Skills 的做法：把 ML 工作流打包成**标准化技能文件**。

一个 **SKILL.md**，YAML 元数据加 Markdown 指令，告诉 Agent 该怎么干活。数据集怎么验证、GPU 怎么选、训练脚本怎么写，全写在里面。

关键是**跨平台通用**。Claude Code、Codex、Gemini CLI、Cursor，同一份技能文件，**四个 Agent 都能读懂**。

---

## 9个技能覆盖全流程

从数据到部署，**完整 ML 流水线**都有对应技能：

数据集创建和管理、模型微调（支持 **SFT/DPO/GRPO** 三种方式）、模型评估和报告、实验追踪和可视化、计算任务提交、Hub 操作、Gradio Demo 构建、论文发布。

不用自己写训练流程，**一句话指令就够**。比如告诉 Codex"用 codeforces-cots 数据集微调 Qwen3-0.6B"，它**自动验证数据格式**、选硬件、提交任务、生成报告。

---

## 实测数据

HuggingFace 官方博客的实测：

用 Codex + Skills 微调 **Qwen3-0.6B**，训练 20 分钟，**成本 $0.30**，HumanEval 基准提升了 10%。

另一个案例：用 Skills 教 Agent 写 CUDA kernel，准确率从 **60% 直接拉到 95%**。技能文件只有 **520 个 token**，但效果差了 35 个百分点。

小模型配上好技能，有时候比大模型裸跑还强。

---

## 适合谁用

适合：经常用 AI Agent 做 ML 相关工作的开发者，想把**重复的训练流程标准化**的团队，或者想让**便宜的小模型干大模型的活**的人。

不适合：不碰模型训练的纯应用开发者，或者 ML 流程已经很成熟、不需要 Agent 介入的团队。

门槛：需要**命令行基础**，跑训练需要 **HF Pro 计划**。纯读技能文件不需要付费。

---

## 如何获取

GitHub: huggingface/skills
Apache 2.0 开源，git clone 即用。

Claude Code 直接 /install-plugin 安装。
Codex 放到 .agents/skills/ 目录。
