# Agent不会训练模型？装个技能包就行

你让 Claude Code 帮你微调模型，它选错 GPU、数据格式没验证，跑了半小时报错。换 Codex 试试，同样的坑再踩一遍。

Agent 不缺能力，缺的是领域知识。

HuggingFace 官方出了个开源项目叫 Skills，7.2K Star，做的事情很简单：把 ML 工作流打包成标准化技能文件。一个 SKILL.md 告诉 Agent 数据集怎么验证、GPU 怎么选、训练脚本怎么写。

最关键的是跨平台。Claude Code、Codex、Gemini CLI、Cursor，同一份技能文件四个平台都能用。

官方博客有实测数据。用 Codex + Skills 微调 Qwen3-0.6B，20 分钟，成本 3 毛钱美金。另一个案例，教 Agent 写 CUDA kernel，准确率从 60% 拉到 95%，技能文件才 520 个 token。

9 个技能覆盖从数据集到部署的完整流程。告诉它"微调 Qwen3"，它自己验证数据、选硬件、提交任务、出报告。

门槛说一下：需要命令行基础，跑训练任务需要 HF Pro 计划。纯本地用 Agent 读技能文件不花钱。

GitHub: huggingface/skills
