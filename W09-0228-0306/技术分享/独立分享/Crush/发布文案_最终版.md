# 告别IDE 终端AI编程工具Crush

用AI写代码，你可能习惯了打开VS Code装插件，或者开个网页跟ChatGPT聊。

但如果你是终端党，这些方案都不够优雅。

Charm团队（做Bubble Tea和Gum那帮人）出了个新工具叫Crush，GitHub 20.6K星，前身是OpenCode。一句话说：终端里的AI编程搭档。

1️⃣ 最大的卖点是多模型自由切换

支持14家AI提供商，Anthropic、OpenAI、Google、Groq都有。同一个会话里中途换模型，上下文不丢。用Claude想架构，切GPT写代码，再换本地模型审查，一气呵成。

2️⃣ 不是把代码当文本丢给AI

内置LSP集成，就是IDE用来理解代码结构的那套底层协议。Crush能读懂函数调用和类型定义，补全准确度比纯文本聊天高不少。

3️⃣ MCP协议扩展，全平台覆盖

可以接外部工具和服务。macOS、Linux、Windows、BSD甚至Android都能跑。Homebrew一行命令装完，5分钟上手。

4️⃣ 说说局限

和Claude Code比，代码理解深度还有差距，社区也坦诚承认这点。如果你只用一个模型、习惯GUI，可能不需要它。

但如果你在终端里工作，想要一个开源、不绑定厂商的AI编程助手，Crush值得花10分钟试试。

打开终端输入：
brew install charmbracelet/tap/crush
