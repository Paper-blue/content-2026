## 痛点

用 Claude Code 写过项目的人大概都经历过这种事。

你说"帮我加个用户登录功能"，它二话不说就开始写代码。**不问需求**，不画架构，测试更是想都没想过。

写完一看，能跑。但隔天改个小需求，整个模块就崩了。

AI 写代码的速度是快了，**代码质量**却像在开盲盒。

---

## 它是什么

**Superpowers**，一个给 Claude Code 装上开发纪律的技能框架。

Jesse Vincent 做的，GitHub **64K** 星，已经进了 Anthropic 官方插件市场。

核心思路就一件事：让 AI 在动手写代码之前，先走完专业开发者该走的流程。

---

## 头脑风暴

第一步不是写代码，是**提问**。

你说想做一个功能，Superpowers 会让 Claude 先问你一串问题：用户是谁、边界在哪、有没有替代方案。

反复确认之后，生成一份设计文档。你同意了，才进入下一步。

跟资深工程师开需求会的感觉差不多。

---

## 拆任务 + TDD

设计通过之后，Superpowers 把工作拆成**2-5分钟**的小任务。

每个任务有明确的文件路径、代码内容和验证步骤。

而且强制走 TDD：先写测试，看它失败，再写最少的代码让它通过。如果 Claude 偷偷跳过测试直接写代码，**Superpowers 会删掉代码让它重来**。

测试覆盖率通常在 **85-95%**，企业级水准。

---

## 子 Agent 架构

每个小任务交给一个独立的**子 Agent** 执行。

子 Agent 只拿到自己任务需要的上下文，不会被其他任务的信息干扰。做完之后还有两轮审查：先查规格是否对齐，再查代码质量。

解决了 Claude Code 最头疼的问题——**上下文窗口耗尽**。15 个文件以上的功能也能稳定交付。

---

## 适合谁用

适合你，如果：你用 Claude Code 做正经项目，写的代码要上线、要维护、不能出大问题。

不适合，如果：你只是让 AI 帮忙写个脚本或原型，几十行代码的事，走完整流程反而慢。

**有编程项目在手**的开发者，值得花 1 分钟装上试试。纯聊天场景用不到。
