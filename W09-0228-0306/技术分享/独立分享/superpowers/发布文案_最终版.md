# 64K星插件让AI编程告别裸奔

用 Claude Code 写过项目的人应该都有这种体验：你说"加个登录功能"，它直接开始写代码。不问需求，不写测试，改天一碰就崩。

Superpowers 解决的就是这个问题。

1️⃣ 它是一个 Claude Code 的技能框架，GitHub 64K 星，已经进了 Anthropic 官方插件市场。作者是 Jesse Vincent，做过不少知名开源项目。

核心思路：让 AI 写代码之前，先走完专业开发者该走的流程。

2️⃣ 装上之后，你说想做一个功能，Claude 不会直接动手。它会先问你一串问题，反复确认需求边界，生成设计文档。你同意了才进下一步。

然后把任务拆成 2-5 分钟的小块，每块有明确的文件、代码和验证步骤。

3️⃣ 最关键的是强制 TDD。先写测试，看它失败，再写代码让它通过。Claude 要是偷偷跳过测试，Superpowers 会删掉代码让它重来。

测试覆盖率通常 85-95%，企业级水准。

4️⃣ 每个小任务交给独立的子 Agent 执行，只拿自己需要的上下文。解决了 Claude Code 最头疼的上下文窗口耗尽问题，15 个文件以上的大功能也能稳定交付。

5️⃣ 安装就一行命令：
/plugin install superpowers@superpowers-marketplace

需要有 Claude Code 订阅，适合做正经项目的开发者。写个小脚本就没必要了，完整流程反而慢。

有编程项目在手的话，花 1 分钟装上试试，差别挺明显的。
