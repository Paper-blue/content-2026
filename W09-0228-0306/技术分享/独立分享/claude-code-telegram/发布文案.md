# 手机遥控 Claude Code 写代码，这个开源项目做到了

Claude Code 在电脑上跑着任务，你得出门。合上笔记本任务断了，带着又太重。

claude-code-telegram 把 Telegram 变成远程终端。手机上发消息，Claude 在你电脑上执行。编辑文件、跑 git、分析代码，和坐在电脑前一样。

1.7K Star，这周涨了 900 多，Python 写的，一行命令装完。

不只是文字聊天。发语音，whisper.cpp 本地转文字。发截图，Claude 识别报错。发 PDF，直接分析。Claude 也能反过来给你发文件。

还有 cron 定时任务和 GitHub Webhook。代码健康检查每天自动跑，CI 挂了主动通知。

门槛说实话不低：Python 3.11+、Claude Code CLI、Anthropic Max 订阅 $100/月起。但如果你已经在用 Claude Code，配置 15 分钟就能搞定。

每天通勤 30 分钟以上的开发者，值得折腾一下。
