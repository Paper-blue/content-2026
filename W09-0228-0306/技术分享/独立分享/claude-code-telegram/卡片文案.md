## 封面

**claude-code-telegram**

用 Telegram **远程操控**你电脑上的 Claude Code。

**1.7K Star**，本周涨了 900 多。

---

## 痛点在哪

Claude Code 在电脑上跑着一个大任务，你得出门了。

合上笔记本？任务断了。带着电脑？太重了。等回来再看？可能早就跑完了，**结果你不知道对不对**。

更常见的情况：通勤路上突然想到一个 bug 的修法，想让 Claude 试一下，但手边**只有手机**。

---

## 核心能力

Telegram 变成你的远程终端。

在手机上用**自然语言**跟 Claude Code 对话，它在你电脑上执行。分析代码、编辑文件、跑 git 命令，和坐在电脑前一样。

关键是**会话不断**。每个项目的上下文自动保存在 SQLite 里，切换项目就像切换聊天窗口，Claude 记得你之前做到哪了。

---

## 不只是聊天

支持的不只是文字。

**发语音**，本地 whisper.cpp 转文字后交给 Claude。**发图片**，Claude 能识别截图里的报错信息。**发 PDF**，直接分析文档内容。

Claude 也能反过来给你**发文件**。生成的代码、导出的报告，直接在 Telegram 里接收。

---

## 自动化玩法

内置 **cron 定时任务**。

每天早上自动跑一遍**代码健康检查**，结果推到 Telegram。配合 **GitHub Webhook**，PR 合并、CI 失败，Claude 主动通知你并给出分析。

不用一直盯着，Claude **自己干活自己汇报**。

---

## 折腾门槛

门槛不低，先说清楚。

需要 **Python 3.11+**、**Claude Code CLI**、Anthropic Max 订阅（**$100/月起**）。还要自己申请 Telegram Bot Token。

安装倒是一行命令：
`uv tool install git+https://github.com/RichardAtCT/claude-code-telegram@v1.3.0`

电脑要保持**开机联网**，手机上 Telegram 随时能连。整个配置大概 **15 分钟**。

---

## 适合谁

适合：已经在用 Claude Code 写代码，经常需要**离开工位但不想断开工作流**的开发者。

不适合：不用 Claude Code 的人，或者**只在电脑前写代码**、没有远程需求的人。

如果你每天通勤超过 **30 分钟**，又想把这段时间变成**有效编程时间**，值得折腾一下。
