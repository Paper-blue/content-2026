# AI 行业日报｜04-10

今天最值得盯的，不是某一家又发了新模型，而是三条线同时往前走了：写代码这门生意开始重新分层，语音和 Agent 往真实工作流里贴，上游算力和机器人执行链路都在继续上收。

## 01. OpenAI 推 100 美元 Codex 档位

4 月 10 日凌晨，OpenAI 推出每月 100 美元的 Pro 5x 档位，补上 20 美元 Plus 和 200 美元 Pro 之间的空档，目标就是高频写代码的人。

新档位给到约 5 倍 Codex 使用额度，官方还说截至 5 月 31 日会有额外提升。OpenAI 披露，Codex 周活已经超过 300 万，近三个月增长约 5 倍。

价格不是重点。重点是 OpenAI 开始把“写代码”从聊天功能里单独拎出来做生意。20 美元守住轻用户，100 美元去抢重度开发者，200 美元继续往团队协作和高负载场景上抬。

## 02. 字节发布全双工语音模型 Seeduplex

字节 Seed 正式发布原生全双工语音大模型 Seeduplex，并已经在豆包 App 全量上线。它不再等用户一句说完再回，而是边听边说，先把实时语音对话最容易翻车的节奏问题拿下。

官方给出的指标很直白：误回复率和误打断率减少一半，抢话比例下降 40%，判停和打断响应分别缩短约 250ms 和 300ms，整体满意度绝对值提升 8.34%。

语音助手真正难的，从来不是会不会说，而是别抢话。字节这次盯住的不是参数，而是通话体验本身。谁先把这件事做顺，电话、客服、耳机、车机这些入口都会被重新定义。

## 03. Anthropic 评估自研 AI 芯片

路透消息称，Anthropic 正在评估自研 AI 芯片的可行性，想在高端 AI 芯片持续紧张的背景下，把训练和推理的主动权再往自己手里收一点。

现阶段它仍主要依赖 Google TPU、AWS Trainium 和 Nvidia GPU。Broadcom 最新披露的协议会在 2027 年给它带来约 3.5 吉瓦 Google 算力，而 Anthropic 自己则说年化收入已经超过 300 亿美元。

这不是一家模型公司突然想学做芯片，而是头部模型公司开始把算力看成产品本身的一部分。模型再强，只要命门捏在别人机房里，议价权就不会完整。

## 04. 阿里云百炼把 Agent 记忆做成基础设施

阿里云百炼上线 Agent 记忆库，给 Agent 补上提取、存储、检索、注入四个环节，让它能跨会话记住用户偏好、日程和历史任务，而不是每轮都从零开始。

百炼给出的数据是：记忆搜索判定平均 RT 下降 50%，日期相关性提升 66%，内容相关性提升 39%。这项能力现在限时免费，也能通过 API 接到别的 Agent 应用里。

今年 Agent 卷到后面，拼的不会只是会不会调工具，而是能不能把同一个用户越用越懂。记忆一旦做成基础设施，中间层产品很快就会被拉开体验差距。

## 05. Meta 交出 Muse Spark

Meta 发布超级智能实验室第一款模型 Muse Spark，主打原生多模态、工具调用和多 Agent 协作，已经上线 Meta AI 和 Meta AI App。

官方称它在 HealthBench Hard 上拿到 42.8 分，并和 1000 多名医生一起构建了训练数据；Meta 还说，新预训练堆栈达到同等能力所需的算力，比 Llama 4 Maverick 低一个数量级以上。

Meta 这次先补的，其实是回到牌桌的资格。它不再急着谈开源路线，而是先证明自己还有从零重起一套前沿模型栈的能力。对 Meta 来说，这比单次 benchmark 更值钱。

## 06. 智元发布 GO-2 基座模型

智元推出具身基座模型 GO-2，把动作思维链和异步双系统架构放进统一框架，想解决机器人里最难的一段：从会规划，到能稳定执行。

官方给出的基准测试里，GO-2 在 LIBERO 四类任务上的平均成功率达到 98.5%，在 LIBERO-Plus 拿到 86.6%，真实迁移测试里也高于 π0.5。

具身智能现在最缺的不是演示视频，而是从“看懂任务”到“手别抖”的那一步。GO-2 把动作规划显式化，说明行业开始从堆模型，转向补执行链路。

## 07. 美团把 Agent 塞进浏览器

美团 GN06 推出 AI 浏览器 Tabbit 公测版，路线很明确：不再让普通用户学一套新的 Agent 玩法，而是直接贴在原本就已经打开的网页工作流上。

团队称模型接入保持开放，头部模型厂商占比都没超过 30%；目前已经有跨境电商、论文整理和无障碍办公等用户案例，整体留存也过了工具类产品的优良线。

浏览器看起来不性感，但它离真实工作流最近。谁能在“你已经开着的标签页”里把活接过去，谁更有机会把 Agent 从演示产品变成日用品。

## 08. 腾讯开源 tRPC-Agent-Python

腾讯开源 tRPC-Agent-Python，补上 Go 版之后的 Python 路线，直接给出 Chain、Parallel、Cycle、GraphAgent 等多种编排方式。

框架把 MCP、RAG、Session / Memory、CodeExecutor、FastAPI 服务化和 OpenTelemetry 可观测接在一起，同时支持 Anthropic、OpenAI 和 LiteLLM 等模型侧对接。

这类框架真正传出的信号，不是又一个开源项目，而是大厂开始把内部 Agent 工程经验拆成标准件往外放。框架越成熟，企业落地就越像搭系统，不像做实验。
