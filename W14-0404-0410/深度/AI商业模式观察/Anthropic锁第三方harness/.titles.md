## Step 4：自检清单

### 首选 #1《一个人花200块吸了5000美元算力，Anthropic这次先眨眼》

- [x] **立场**：有（"先眨眼"是作者判断 Anthropic 扛不住的态度）
- [x] **指向**：有（读者看标题知道在讲订阅制被打穿这件事）
- [x] **场景**：有（"一个人""200块""5000美元算力"具体到可视化）
- [x] **无 emoji**
- [x] **无博眼球词**（震惊/炸了/太牛/绝了 都没用）
- [x] **数字节制**：只用了 $200 和 $5000 一对反差数字
- [x] **字数 25 字**，在微信标题上限 30 字以内
- [x] **前 20 字包含核心关键词**（一个人、200块、5000美元、算力）

### 选择理由

候选 #1 相比其他候选的优势：
- **#2 太干净但缺数据钩子**——"订阅制这张皮撑不住了"读起来像小标题，不够有冲击
- **#3 有悬念但缺指向**——读者不知道 Boris 说了啥，点击率高但信息量低
- **#4 数字不够直觉**——"13.5 万个 OpenClaw"需要知道 OpenClaw 是啥才能共情

**#1 的"一个人花200块"是典型的"替读者算账"结构**——把抽象的套利问题落到"一个人"的视角上，把 Anthropic 的动作和"先眨眼"的态度绑在一起，既有数据冲击又有判断立场。

## 最终选定

**title**: 一个人花200块吸了5000美元算力，Anthropic这次先眨眼

**subtitle**: 4月4日12点PT，Anthropic把13.5万个OpenClaw挡在了订阅门外。不是闭源打压开源，是订阅制这张皮在Agent时代撑不住了。
