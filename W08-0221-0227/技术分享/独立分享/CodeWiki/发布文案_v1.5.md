# 如果代码库会自己写文档

有多少人看过这种场景：README 写着"文档即将更新"，一年过去了还是那句话？

代码改了100次，文档还停在v1.0。

谷歌刚推出的AI代码文档神器 Code Wiki，专治"代码看不懂、文档跟不上"。

一键操作：输入GitHub链接，AI自动分析，生成完整Wiki。核心价值：让任何开源项目都有一份"永远最新"的说明书。

5大核心功能。

自动文档生成。系统概览、模块说明、类函数详解，一次性全部生成。

实时同步更新。每次代码提交，文档自动刷新，永远不会过期。

可视化架构。自动绘制架构图、类图、序列图，项目结构一目了然。

智能AI助手。Gemini驱动，自然语言问答，问"这个模块干什么的"就行。

播客生成。还能自动生成双人对话播客，边听边学代码。

适用场景。

快速理解大型项目。1万+文件的开源项目，打几把游戏的功夫就搞定。

新人入职加速。新员工70%的问题，直接问AI就能解决。

代码审查辅助。双向导航（文档↔代码），快速定位问题。

团队协作提效。QA、架构师、产品经理都能实时了解代码逻辑。

真实效果数据。

某开源项目集成后：新手首次贡献成功率70%（无需人工指导），文档相关Issue下降83%，月活跃贡献者增长60%。

技术原理：Tree-sitter语法树 + 知识图谱 + Gemini AI。

使用限制。

目前支持所有公开GitHub仓库（完全免费）。私有仓库需加入waitlist，即将开放企业支持。小缺点：复杂项目可能回答不完整，需要人工补充。

官网：https://codewiki.ai/

使用步骤：输入GitHub仓库地址，AI自动分析生成Wiki，开始用自然语言提问。
