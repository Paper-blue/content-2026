# 开源极简AI编码助手，不依赖任何厂商🛠

用 Claude Code 写代码，想临时换个模型试试。
换不了，上下文全没了。

1️⃣ pi-mono 是什么

libGDX 作者 Mario Zechner 做的 AI Agent 工具包，14.3K⭐️，TypeScript 写的，去年 8 月开始做，现在已经有 150 多个版本。

理念很极简：一个编码 Agent，只需要 4 个工具——读文件、写文件、编辑文件、跑命令。没有计划模式，没有 MCP，系统 prompt 不到 1000 token，是 Claude Code 的十分之一。

打开终端，`npm install -g @mariozechner/pi-coding-agent`，然后在项目目录运行 `pi`，就能用了。支持 Claude、GPT、Gemini，随便换。

2️⃣ 不只是个编码工具

如果你想把 AI 能力嵌进自己的产品，pi-mono 还有几个包可以单独用。

`pi-ai` 这个包屏蔽了各家模型 API 的差异，一套格式，支持跨模型的上下文迁移。在 Claude 里开的对话，换 GPT 继续，格式自动转换，不用自己写适配层。

`pi-tui` 做终端界面，`pi-web-ui` 做浏览器 UI，`pi-mom` 接 Slack，各取所需。

3️⃣ 适合谁

用 TypeScript 做项目、想搭一个不依赖某家云的 AI 工作流，或者想快速给团队工具加 AI 能力的开发者，值得花一两小时试试。

不太适合：只想找个 GUI 工具用用的，或者项目不是 TypeScript 生态的。

另外有个真实体验：有开发者折腾了一段时间后觉得"优化成了目标本身"，反而忘了用工具做事。pi-mono 功能多，用的时候保持目标清晰更重要。
