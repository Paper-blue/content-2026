# 一个人做事，但AI团队在背后🤖

你有没有试过，一边查资料、一边写初稿、一边改格式？

一个窗口跳到另一个窗口，查完忘了，回头再查一遍。
不是效率问题，是大脑本来就不擅长多线程。

那如果把这三件事拆开，交给三个 AI 去做呢？

研究员专门收集资料，撰稿人拿到资料后起草初稿，编辑审核修改输出终稿。

任务在它们之间自动流转，你只需要在最开始定义好任务，最后拿结果。

这就是 CrewAI 在做的事。

1️⃣ 框架核心：给每个 AI 分配角色和目标。不是随便调用，而是真正的分工协作，每个 Agent 知道自己在整个流程里的位置，能读取上一个 Agent 的输出，也能委托任务给其他 Agent。

2️⃣ 两种流程可以选：顺序执行（A 做完给 B），或者层级执行（有 Manager 来调度分派）。不同任务用不同模式，配置写在 YAML 文件里，不需要改逻辑代码。

3️⃣ 门槛说清楚：需要 Python 3.10+，有 LLM 的 API Key（OpenAI 或其他都支持）。安装大概 10 分钟，跑通第一个 Crew 大概 20-30 分钟。有命令行基础就够了，不需要懂底层原理。
