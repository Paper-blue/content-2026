你有没有试过同时写报告、查资料、改格式？

大多数人的做法是一个窗口跳来跳去。查一段，切回来写，发现忘了刚才查的什么，再查一遍。

**CrewAI** 是另一条路：把这三件事交给三个 AI，让它们自己协作完成。

---

## AI 团队怎么运作

CrewAI 的核心概念很直接：给每个 AI 分配一个**角色**、一个目标、一段背景。

研究员只负责收集资料，写手拿到资料后起草初稿，编辑拿到初稿后审核修改。

任务流动是自动的，不需要你手动复制粘贴。

---

## 三种角色，一次运行

用 CrewAI 搭一个内容生产团队，大概是这样的：

**研究员**：负责搜集特定主题的信息，输出结构化资料。

**撰稿人**：接收资料，按要求格式写出初稿。

**编辑**：对初稿做质量审核，给出修改建议或直接输出终稿。

三个 Agent，一行命令启动，全程无需干预。

---

## 不只是串联，是真正的协作

普通 AI 调用是单线程的：你问，它答，下一个问题要重新解释背景。

CrewAI 的 Crew 里，每个 Agent 都知道自己在整个任务里扮演什么角色，可以读取前一个 Agent 的输出，也可以向别人委托任务。

**44.4K stars**，在 GitHub 上是目前最受关注的多 Agent 框架之一。2024 年初发布，一年不到进了多 Agent 框架前三。

---

## 支持的流程类型

两种任务流程可以选：

**顺序执行**（Sequential）：Agent A 做完给 Agent B，B 做完给 C，适合有明确先后依赖的任务。

**层级执行**（Hierarchical）：有一个 Manager Agent 负责分派和协调，适合任务边界不清晰、需要动态调度的场景。

不同场景用不同流程，不需要额外代码。

---

## 适合谁用

适合你，如果：你在做**内容生产、调研报告、数据处理**这类有明确分工的工作，想把重复性的流程自动化。

不适合，如果：你只是偶尔问问 AI 问题，ChatGPT 或 Claude 单独用够了。

门槛说明：需要 Python 3.10+，懂命令行，有 OpenAI 或其他 LLM 的 API Key。配置文件用 YAML 写，不需要深入学代码。**安装大概 10 分钟，第一个 Crew 跑通大概 20-30 分钟**。

## 如何获取

GitHub：github.com/crewAIInc/crewAI

安装命令：

pip install crewai

pip install 'crewai[tools]'

官方文档有完整示例，包括内容写作、市场分析、行程规划等场景。
