# AI每次对话都失忆？mem0治好了这个病

周一打开 Claude，介绍项目背景。

周二打开，再介绍一遍。

周三打开……你懂的。

相当于每天跟一个失忆症患者解释同一件事。不是 AI 不够聪明，是它根本没有跨会话的记忆机制。

---

mem0 就是专门解决这个问题的开源项目，47.7K ⭐，现在是 AI Agent 记忆层的标准解法之一。

核心思路是在 AI 和用户之间加一层持久化记忆。对话结束，mem0 自动提取关键信息存起来——你的偏好、项目背景、历史决策。下次打开，AI 已经知道你是谁。

在 LOCOMO 基准测试里，跟 OpenAI 官方 Memory 对比，准确率高 26%，Token 用量少 90%。

Token 少 90% 不是靠截断，是因为不再把全部历史塞进上下文——只检索和当前对话相关的记忆片段，精准喂给模型。这才是省的地方。

---

接入门槛不高。pip install mem0ai，核心 API 三个：add 存记忆、search 找记忆、get 取记忆。支持 OpenAI、Claude、Mistral，也支持本地模型。五分钟能跑通一个带记忆的 demo。

需要能用命令行，配过一次 API Key。装过 LangChain 的话，比它容易。
