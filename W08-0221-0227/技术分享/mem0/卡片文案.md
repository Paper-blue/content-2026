# mem0：给AI装上长期记忆

**47.7K** ⭐ 的开源项目，解决一个被反复忽略的问题：AI 每次对话都是失忆。

对比 OpenAI 官方 Memory：准确率 **+26%**，Token 用量 **减少 90%**。

---

## 你每天在重复什么

打开 Claude，介绍项目背景。
关掉，第二天再开，再介绍一遍。

不是 AI 不够聪明，是它根本**没有记忆**。每次对话都从零开始，你教过它的一切，下次见面全忘光了。

这不是个小麻烦。一个重度用 AI 工作的人，每周在「重新介绍自己」上能浪费一两个小时。

---

## mem0 的做法

核心就一件事：在 AI 和用户之间加一层**持久化记忆**。

对话结束后，mem0 自动提取关键信息——你的偏好、项目背景、习惯、历史决策。下次打开，AI 已经知道你是谁，直接从上次停下来的地方继续。

三层存储结构：向量数据库做语义检索，图数据库存实体关系，键值存储快速访问。AI 联想记忆，不是翻聊天记录。

---

## 接入有多简单

安装一行：
```
pip install mem0ai
```

核心 API 只有三个：`add`（存记忆）、`search`（找记忆）、`get`（取记忆）。

**五分钟**可以跑通一个带记忆的聊天 demo。支持 OpenAI、Claude、Mistral、LLaMA 等主流模型，也可以自己接向量库（Qdrant、Pinecone、Weaviate 等）。

云托管版直接调 API，免配置。

---

## 真实跑分数据

LOCOMO 基准测试，与 OpenAI 官方 Memory 正面对比：

- 准确率：**+26%**
- P95 响应延迟：**快 91%**
- Token 消耗：**少 90%**

90% 的 Token 减少不是裁剪，是因为不再每次把全部历史塞进上下文——只检索相关记忆片段，精准喂给模型。

---

## 适不适合你

适合：在用 Claude / GPT / Cursor 做项目的开发者、产品人；需要 AI 助手长期记住你的工作风格；在搭 Agent 或 Chatbot，需要跨会话保持上下文。

不适合：只是偶尔用 ChatGPT 问问题，不在意每次重新介绍；或者用的是纯网页版工具，没法接 API。

**门槛判断**：需要能用命令行，配过一次 API Key。如果你装过 LangChain 或 LlamaIndex，这个比它们容易。
