# 把软件公司装进一行代码里，MetaGPT怎么做到的🔧

想过一个小产品的想法，但光搭项目骨架就耗掉半天。需求文档、系统设计、代码实现，原本是三个不同角色的事。

1️⃣ MetaGPT是什么

64K星的开源框架，模拟一个完整的软件公司。你输入一行需求，内部的产品经理Agent先跑——分析需求、写用户故事、出竞品分析。然后架构师接手，出系统设计和数据结构定义。最后工程师写代码，QA跑测试。

不是一个AI干所有事，是五个专职角色在流水线上接力。

2️⃣ 为什么不是一般的多Agent

核心是SOP（标准操作流程）。传统多Agent系统容易"级联幻觉"——一个Agent出错，后面全跑偏。MetaGPT把人类软件团队的工作流程编码成SOP，每个角色的输出有格式约束，下一个角色拿到的是结构化数据。

在代码生成基准测试上，首次尝试成功率85.9%。这个数字比大多数单模型代码工具高一截。

3️⃣ 用起来什么感觉

门槛不算低，需要Python 3.9以上，还要有自己的LLM API Key（支持OpenAI，也支持Ollama本地模型）。配置文件要手动改，不是装完即用。

适合场景：快速验证产品原型，"我有个想法，想看能不能跑通"。拿来做生产级项目还得人工review，当工具用，别当团队用。
