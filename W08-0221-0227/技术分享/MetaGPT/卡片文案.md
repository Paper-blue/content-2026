## 痛点

你想验证一个产品想法。

光是搭项目骨架、写需求文档、出系统设计，就得花掉一个下午。还没开始写代码，已经精疲力竭了。

现有的 AI 工具，要么只能写代码片段，要么给你一堆上下文不一致的文档。没有一个真正从需求到代码全打通的。

---

## 它是什么

MetaGPT 模拟了一个软件公司的运作方式。

**产品经理 Agent** 拿到你的需求，输出 PRD 和用户故事。**架构师 Agent** 接手，出系统设计和数据结构。**工程师 Agent** 写代码，**QA Agent** 跑测试。

五个专职角色，流水线接力，你只需要输入一行需求。

---

## SOP 防幻觉

普通多 Agent 系统的问题是"级联幻觉"——一个 Agent 出错，后面全跑偏。

MetaGPT 的做法是：把软件团队的工作流编码成 **SOP（标准操作流程）**，每个角色的输出都有格式约束，下一个 Agent 拿到的是结构化数据，不是自由发挥的文字。

**代码生成基准测试首次尝试成功率 85.9%**，不是宣传语，是 HumanEval 测试下的结果。

## 门槛说明

需要 Python 3.9+，配置 `~/.metagpt/config2.yaml` 填入 API Key。

支持 OpenAI、Ollama 等本地模型。装完到跑通第一个需求，大概 20-30 分钟。

## 适合谁

适合你，如果：你在做产品原型验证，想快速看到从需求到代码的完整交付，不想一步一步手动串联各种 AI 工具。

不适合，如果：你只需要补全几行代码，GitHub Copilot 够用了。生产级项目还需要人工 review，把它当原型工具，不要当团队替代。

## 如何获取

GitHub: geekan/MetaGPT（**64K ⭐️**）

安装：

pip install metagpt

配置 `~/.metagpt/config2.yaml`，填入 LLM API Key，运行第一个需求：

metagpt "写一个待办事项管理应用"
