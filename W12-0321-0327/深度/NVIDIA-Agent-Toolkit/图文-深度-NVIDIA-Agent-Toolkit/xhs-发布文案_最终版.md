GPU卖到爆，NVIDIA偏偏开始给别人写软件

H100和B200排着长队等发货，利润率接近60%。黄仁勋偏偏在GTC上发布了Agent Toolkit——一整套开源软件平台。芯片公司为什么跑去做软件？

答案藏在Agent经济里。训练是一次性峰值负载，Agent是7×24小时持续推理。每多一个Agent跑起来，就多一份持续的GPU租金。NVIDIA要的不是卖更多芯片，而是让更多Agent消耗算力

这条路跟Android很像。Google开源Android统一移动系统承载广告，NVIDIA开源Agent Toolkit统一运行层承载算力消费。手法一样，赌注不同
