# 《穷查理宝典》AI时代重读 系列大纲

> 作者：查理·芒格（Charlie Munger）/ 彼得·考夫曼 编
> 出版年：2005年（Poor Charlie's Almanack）
> 核心命题：多元思维模型——跨学科思考才能做出好决策
> AI对照轴：AI拥有所有学科的知识，但它的"多元"和芒格说的"多元"是两回事
> 系列期数：5期

---

## 系列总线

芒格一生推崇"多元思维模型"：从不同学科借用核心概念来理解世界。2026年，AI看起来是终极多元思维者——它读过所有学科的教材。但芒格说的"多元"不是知识量大，是知道什么时候用什么模型。AI有100个模型但不知道什么时候该用哪个。芒格最反对的"拿着锤子看什么都像钉子"，正是AI最擅长的事。

## 核心对照关系

| 芒格的智慧 | AI时代的验证/挑战 |
|-----------|-----------------|
| 多元思维模型 | AI有知识广度但无判断深度 |
| 逆向思维 | AI做正向优化，不做"预防性悲观" |
| 能力圈 | AI没有边界感，不知道自己不知道什么 |
| lollapalooza效应 | 算法正在批量制造心理偏差叠加 |
| 检查清单 | 人类需要"抵抗AI建议"的清单 |
| "别人贪婪时恐惧" | AI让所有人同时看到同一信息，集体恐惧/贪婪被放大 |
