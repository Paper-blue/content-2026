# OpenClaw接入微信两条路怎么选

上周腾讯发了ClawBot，微信里加个联系人就能用OpenClaw Agent。同一周，社区的openclaw-wechat插件stars过了1400

两条路都能让AI Agent进微信。选哪条取决于你要什么

1️⃣ 社区版openclaw-wechat

开源插件，MIT协议。通过代理服务连你的个人微信，扫码登录。支持私聊群聊，能收发文字和图片

一行命令装：openclaw plugins install @canghe/openclaw-wechat。配置要填API Key和代理地址

好处是Agent跑在你自己机器上，插件工具你配，数据不过第三方。坏处是要自己运维代理服务，个人微信有封号风险。作者标了仅供学习研究

2️⃣ 官方版ClawBot

腾讯3月22号发的。不用扫码不用部署，微信里加ClawBot好友直接聊。能处理文件、发邮件、跑自动化

开箱即用，微信原生体验。代价是Agent的能力和数据都在腾讯手里，能干什么由腾讯说了算

3️⃣ 一句话总结

想折腾要隐私要定制，社区版。想省事要稳定不怕托管，官方ClawBot

你会选哪条路？
