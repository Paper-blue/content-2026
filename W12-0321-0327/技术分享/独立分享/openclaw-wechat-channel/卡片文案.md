## OpenClaw × WeChat

上周腾讯发布了 ClawBot，在微信里加一个联系人就能用 OpenClaw Agent。同一周，社区的 **openclaw-wechat** 插件 stars 突破 1400

两条路都能让 OpenClaw 接入微信。选哪条，看你要什么

---

## 先说背景

OpenClaw 是跑在终端里的 AI Agent。能读文件、写代码、调工具，但它不会主动找你。你得开终端跟它对话

如果你想在微信里直接跟 Agent 聊天，让它帮你处理消息、回复问题、跑自动化任务，就需要一个**通道插件**把微信和 OpenClaw 连起来

---

## 社区版：openclaw-wechat

freestylefly 做的开源插件。**1400+ Stars**，MIT 协议

原理是通过代理服务连接个人微信。登录方式是扫码，设备类型模拟 iPad 或 Mac。支持**私聊和群聊**，能收发文字和图片

安装一行命令：`openclaw plugins install @canghe/openclaw-wechat`。配置需要填 API Key、代理地址和 webhook 地址

优点是灵活。你可以配多个微信账号，自定义消息处理逻辑，Agent 的能力完全由你控制

限制也明确：需要自己部署代理服务，个人微信有封号风险，作者标注了**仅供学习研究**

---

## 官方版：腾讯 ClawBot

2026年3月22日发布。腾讯官方把 OpenClaw Agent 做成了微信里的一个**联系人**

不需要扫码，不需要代理服务。在微信里加 ClawBot 好友，直接发消息就能用。它能处理文件传输、发邮件、跑自动化任务

腾讯围绕它推了三个配套产品：**QClaw**（个人用户开箱即用）、**Lighthouse**（开发者做定制）、**WorkBuddy**（企业管控）

限制是你用的是腾讯托管的 Agent，不是你自己的。能力范围由腾讯决定

---

## 怎么选

两个方案解决同一个问题，但思路完全不同

社区版是**你控制一切**。Agent 跑在你的机器上，插件和工具你自己配，数据不经过第三方。代价是要自己运维，有封号风险

官方版是**开箱即用**。不用部署，不用配置，微信原生体验。代价是 Agent 的能力和数据都在腾讯手里

想折腾、要隐私、要定制 → 社区版
想省事、要稳定、不怕数据托管 → 官方 ClawBot
