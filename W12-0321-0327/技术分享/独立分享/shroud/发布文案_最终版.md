# 你的AI Agent通过安全审计了吗

你让Agent帮你部署服务，它能读到.env里的数据库密码。你让它调试网络，API密钥直接暴露。你让它执行命令，一句rm -rf就能把项目删了

OpenClaw默认不做安全审计。你不检查，就不知道环境里有多少个洞

1️⃣ SecureClaw做了什么

Adversa AI开发的OpenClaw安全插件。装上之后对你的Agent环境跑56项自动检查，扫暴露端口、弱文件权限、明文凭据、关闭的沙箱。每条结果都标注OWASP和MITRE框架编号，不是笼统说你不安全，而是告诉你这个风险属于哪类攻击

插件和技能双栈架构。插件层在运行时拦截，技能层把15条行为规则注入Agent上下文。遇到可疑指令拒绝执行，高风险操作需要人工确认

2️⃣ 不只是扫描

带了5个加固模块，扫完直接修。网关绑localhost、敏感目录锁权限、凭据加密、Docker隔离、网络出口收紧

还有3个后台监控常驻运行。.env被改了它知道，凭据文件被动了它知道，AGENTS.md被篡改了它也知道

3️⃣ 上手成本

一行命令安装：openclaw plugins install @adversa/secureclaw。跑一次审计：openclaw secureclaw audit。部署行为规则：openclaw secureclaw skill install

目前唯一把每条规则都映射到OWASP ASI Top 10和MITRE ATLAS的OpenClaw安全工具。开源免费
