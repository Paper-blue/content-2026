# AI的插件商店终于有安检了

给 AI 装插件这件事，之前挺野的。OpenClaw 的 ClawHub 上有一万多个插件，但安全团队一查，2857 个里面 341 个是恶意的，专门偷数据装木马

v2026.3.22 这次更新，把插件安装的规矩从头到尾重写了

1️⃣ 插件安装从路边摊搬进应用商店

以前装插件走 npm 直装加 Chrome 扩展中转，没有任何审查。现在 ClawHub 优先，每个插件自动过 VirusTotal 安全扫描，用 Gemini 3 Flash 做行为分析，不看它说自己能干嘛，看它实际干了什么

Chrome 扩展这条路彻底砍掉了

2️⃣ Plugin SDK 让开发者不再摸黑写代码

旧的 extension-api 正式退役，新的 Plugin SDK 提供标准化开发工具和测试框架。插件之间的 ID 冲突问题也修了，不会再出现装了两个同名插件互相打架的情况

3️⃣ 不止安全，还有几个实用升级

Agent 默认超时从 10 分钟拉到 48 小时，跑长任务的不用再担心半路断线。内置了 Exa、Tavily、Firecrawl 三个搜索引擎，不用自己折腾配置。40 多个安全漏洞全部修复，包括 Windows SMB 凭证泄露

4️⃣ 升级前看一眼

有三个破坏性变更：Chrome 扩展路径删除、环境变量从 MOLTBOT/CLAWDBOT 改成 OPENCLAW、新装默认权限收紧。跑一次 openclaw doctor --fix 基本能自动处理

已装用户一行命令：openclaw update
新用户：npm install -g openclaw，需要 Node.js，10 分钟搞定
