## OpenClaw v2026.3.22

330K+ Stars 的开源 AI Agent 框架，这次大版本更新，重点不是模型更强了，是**插件生态的规则变了**

从安装方式到安全审查，几乎全部重写

---

## 旧版装插件有多野

之前给 OpenClaw 装插件，得靠 Chrome 浏览器扩展做中转。听起来就不太对劲

更离谱的是 ClawHub 上的插件没有安全审查。安全团队审计了 2,857 个插件，发现**341 个是恶意的**，其中 335 个来自同一个攻击者的批量操作。有的插件伪装成"Yahoo Finance"工具，实际上让你下载木马

你以为在给 AI 装工具，其实在给电脑开后门

---

## 现在装插件像装 App

v2026.3.22 做了三件事

第一，**ClawHub 优先安装**。跑 `openclaw plugins install` 不再从 npm 随便拉包，而是先查 ClawHub 的审核仓库，找不到才回退到 npm。相当于从路边摊换成了应用商店

第二，**VirusTotal 安全扫描**。每个插件上传时自动生成 SHA-256 哈希，交叉比对 VirusTotal 的威胁数据库。用 Gemini 3 Flash 做行为分析，不看插件声称能做什么，看它**实际执行了什么**——有没有偷偷下载文件、访问敏感数据、操控 Agent 指令

第三，**Plugin SDK 公开**。旧的 `openclaw/extension-api` 正式退役，新的 `openclaw/plugin-sdk` 提供标准化的开发和测试工具。插件开发者不用再摸黑写代码

---

## v2026.3.22 vs 旧版对比

升级前后差别一张表说清楚：

| 维度 | 旧版（v2026.2.26） | 新版（v2026.3.22） |
|------|-------------------|-------------------|
| 插件安装 | npm 直装，无审查 | ClawHub 优先 + VirusTotal 扫描 |
| 浏览器集成 | Chrome 扩展中转 | 原生会话模式，扩展已移除 |
| 插件开发 | extension-api（已废弃） | Plugin SDK + 测试工具 |
| Agent 超时 | 10 分钟 | **48 小时** |
| 安全漏洞 | 40+ 未修 | 全部修复 + Windows SMB 凭证泄露补丁 |
| 搜索能力 | 需自行配置 | Exa + Tavily + Firecrawl 内置 |

跑长任务的人注意：以前 Agent 跑 10 分钟自动断线，现在**默认 48 小时**

## 升级要注意什么

有三个破坏性变更

旧的 Chrome 扩展路径**彻底删除**了，跑一次 `openclaw doctor --fix` 自动迁移。所有 `MOLTBOT_*` 和 `CLAWDBOT_*` 环境变量要改成 `OPENCLAW_*`。新装的实例默认权限收紧到"messaging"模式，要用文件和终端功能得手动开启 `tools.profile: "full"`

升级命令就一行：`openclaw update`

## 适合谁用

如果你在用 OpenClaw 跑自动化任务、连接外部工具，这个版本必须升。安全补丁 + 48 小时超时 + 内置搜索，三个理由够了

如果你还没用过 OpenClaw，这是个不错的起点。ClawHub 有 **10,000+ 插件**，装起来比之前安全多了

纯聊天用途、不需要 Agent 能力的，用不上
