## DeepClaw

Deepgram 做的开源项目。给你本地跑的 OpenClaw Agent 接上电话线路，用户打个电话就能跟 Agent 语音对话

不是语音转文字再回复那种延迟很高的方案。用的是 Deepgram Voice Agent API，**语音到语音**，首字节延迟 90ms。支持打断、多轮对话、40+种语音

MIT 协议，免费开源

---

## 为什么要让AI接电话

有些场景打字不方便。开车的时候想让 Agent 帮你查东西，做饭的时候想问它菜谱换算，或者你就是觉得跟 AI 说话比打字快

还有商业场景。客服热线接入 Agent，预约提醒自动外呼，多语言电话翻译

键盘是一种交互方式，电话是另一种。DeepClaw 让 Agent 多了一个**入口**

---

## 怎么工作

架构分三层

**电话线路**：Twilio 或 Telnyx 提供真实电话号码。有人打进来，电话信号转成音频流

**语音处理**：Deepgram Voice Agent API 做语音识别和合成。用的是 Flux 语义转写，不是简单的 VAD 静音检测，能准确判断你说完没有。Aura-2 做语音合成，90ms 出声

**Agent 调度**：音频流转文字后发给本地 OpenClaw，Agent 处理完文字回复，再合成语音播回去

整个链路：**你说话 → 语音识别 → Agent思考 → 语音合成 → 你听到回复**

## 成本很低

Twilio 电话号码月租约 1 美元，通话费约 0.008-0.014 美元/分钟。Telnyx 更便宜，号码 0.5-2 美元/月，通话 0.005-0.025 美元/分钟

Deepgram 新注册送 200 美元额度，个人折腾足够用很久

---

## 上手需要什么

Python 3.10 以上。注册 Deepgram 账号和电话服务商（Twilio 或 Telnyx）。本地跑着 OpenClaw。用 ngrok 把本地服务暴露到公网

把 skill 复制到 OpenClaw 的 skills 目录，让 Agent 自己帮你配置。整个过程大概 **15 分钟**

有个已知限制：OpenClaw 的 chat 接口有约 5 秒的缓冲延迟，语音体验会受影响
