## OpenClaw Metacognitive Suite

七个插件，一套认知系统。装上之后，AI Agent 不再是每次对话从零开始的工具，而是一个**会记住、会反思、会成长**的助手

开源项目，MIT 协议

---

## 现在的AI Agent有个致命问题

你跟 AI 聊了三个月，它对你的了解还是零。每次开新对话，它不记得你上次说过什么，不知道你踩过什么坑，更不会从自己的错误里学到东西

上下文窗口一关，**所有经验全部清零**

这不是智能，是金鱼记忆

---

## 七个插件各管一件事

这套插件不是一个大杂烩，而是**七个独立模块**，按职责分工，通过全局事件总线通信

**stability** 监测 Agent 的状态熵值，发现它在兜圈子或偏离原则时自动干预。**continuity** 做跨会话记忆，对话结束后归档，下次启动时语义搜索恢复上下文。**graph** 从对话中提取实体和关系，构建**知识图谱**

三个基础插件，解决"记住"的问题

---

## 学习靠后面四个

**metabolism** 从每次对话中提取关键认知，识别知识缺口。**nightshift** 把缺口变成任务，排进优先级队列，在你不用的时候**自动研究补课**。**contemplation** 做多阶段反思，24小时内经历探索、反思、综合三个阶段。**crystallization** 把反复验证的认知转化为永久特征，相当于**从短期记忆变成长期人格**

最后一步需要人类审批，不会偷偷改自己

---

## 训练模式和冻结模式

两种部署方式

训练模式：七个插件全开，Agent 自主学习。对话归档、知识图谱提取、高熵时刻触发代谢处理，**30天后向量结晶化**

冻结模式：关掉四个学习插件，Agent 保留已学内容但停止学习。适合生产环境，只保留 stability、continuity 和 graph

---

## 适合谁用

如果你在用 OpenClaw 跑长期任务，希望 Agent 越用越懂你，这套插件就是为你设计的

如果你只是偶尔问 AI 一个问题，用完就关，不需要它记住任何东西，装了也浪费资源

门槛说明：需要 git clone 整个仓库，在 openclaw.json 里配置插件路径。**加载顺序有要求**，必须按 stability → continuity → graph → metabolism → nightshift → contemplation → crystallization 的顺序。整个过程大概 15 分钟
