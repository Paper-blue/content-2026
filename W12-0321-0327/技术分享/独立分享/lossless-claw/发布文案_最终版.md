# AI聊久了就忘事这个插件治好了

OpenClaw跑长任务，对话越来越长，上下文窗口装不下了。默认做法是砍掉旧消息。砍完之后，之前讨论的架构决策、排除过的方案，全没了

Agent不是变笨了，是真的忘了

1️⃣ Lossless Claw换了一种思路

不砍消息，压缩存档。所有对话存进SQLite，旧消息压缩成摘要，摘要再压缩成更高层摘要，形成一棵有向无环图。需要的时候展开还原

每次对话拼接方式是：高层摘要加中层摘要加最近32条原始消息。省token，不丢关键信息。3.3K Stars，MIT协议

2️⃣ 三个工具随时回溯

lcm_grep全文搜索历史对话，50轮之前讨论的内容也能找到。lcm_describe查看某段对话的摘要。lcm_expand展开压缩摘要，还原原始细节。压缩是可逆的

3️⃣ 一行命令装上就生效

openclaw plugins install @martian-engineering/lossless-claw。四个参数可调，默认值够用。可以指定便宜的模型专门做摘要，省主模型的钱
