## MemOS Cloud Plugin

OpenClaw 每次开新会话，Agent 对你一无所知。上次聊了什么、你的偏好是什么、哪些方案试过了，全部从零开始

MemOS Cloud 插件给 Agent 加了一层**云端长期记忆**。每次对话结束自动存档，下次对话开始自动召回相关记忆。Agent 越用越懂你

**300+ Stars**，Apache 2.0 协议

---

## 它解决什么问题

你让 Agent 帮你写代码，花了半小时沟通清楚项目结构、技术栈偏好、命名规范。关掉窗口，下次再开，又得重来

不是 Agent 不想记住，是它**没有地方存**。上下文窗口是临时的，会话结束就清空

MemOS Cloud 在会话之外加了一层持久化记忆

---

## 两步完成记忆闭环

插件挂在 OpenClaw 的两个生命周期钩子上

**启动时召回**：新会话开始前，用当前对话的上下文去 MemOS Cloud 做语义搜索，找到相关的历史记忆，注入到 Agent 的上下文里。Agent 还没开口就已经知道你是谁

**结束时存档**：对话结束后，自动把这轮对话的关键信息发送到 MemOS Cloud 存储。不需要你手动标记什么该记住

---

## 支持多Agent隔离

如果你跑多个 Agent 做不同任务，不希望它们的记忆混在一起

开启 **multiAgentMode** 后，每个 Agent 的记忆通过 agent_id 隔离。写代码的 Agent 记住你的技术偏好，写文档的 Agent 记住你的文风，互不干扰

还有**全局召回**模式，跨所有会话搜索记忆，适合找"我之前在某个项目里用过什么方案"这类问题

---

## 配置和成本

安装：`openclaw plugins install @memtensor/memos-cloud-openclaw-plugin`

需要注册 MemOS Cloud 账号拿 API Key。免费额度够个人使用

支持异步模式，存档操作不阻塞对话。配置写在 openclaw.json 里，5分钟搞定
