# 让AI记住你是谁跨会话长期记忆

你让Agent帮你写代码，花了半小时沟通清楚项目结构和命名规范。关掉窗口，下次再开，又得重来

不是Agent不想记住，是它没有地方存

1️⃣ MemOS Cloud给Agent加了云端记忆

OpenClaw的长期记忆插件。对话结束自动存档，下次开始自动召回。挂在两个生命周期钩子上，启动时语义搜索历史记忆注入上下文，结束时把关键信息存到云端

Agent还没开口就已经知道你是谁

2️⃣ 多Agent记忆隔离

开启multiAgentMode，每个Agent的记忆通过agent_id隔离。写代码的记住技术偏好，写文档的记住文风，互不干扰

还有全局召回模式，跨所有会话搜索记忆

3️⃣ 5分钟配好

openclaw plugins install @memtensor/memos-cloud-openclaw-plugin。注册MemOS Cloud拿API Key，免费额度够个人使用。支持异步模式，存档不阻塞对话
