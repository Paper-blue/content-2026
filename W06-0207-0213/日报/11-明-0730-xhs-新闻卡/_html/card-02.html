OpenAI给Agent配了台完整Linux服务器
VentureBeat · 2026-02-11
OpenAI 发布 Responses API 三大更新：Server-side Compaction、Hosted Shell Containers、Skills 标准支持。电商平台 Triple Whale 的代理 Moby 在测试中成功处理 500 万 token 和 150 次工具调用。
Hosted Shell 为每个代理提供 OpenAI 托管的 Debian 12 容器环境，预装 Python 3.11、Node.js 22 等，支持持久化存储和联网能力。
💡 INSIGHT
Server-side Compaction 解决的不是算力问题——是长周期推理的「断片」难题。把基础设施成本转为 API 订阅的典型打法。
