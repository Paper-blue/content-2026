Chrome 新功能让网站变 AI 工具
VentureBeat · 2026-02-13
Google Chrome 团队于本周在 Chrome 146 Canary 版本中发布 WebMCP（Web Model Context Protocol）早期预览。通过新浏览器 API navigator.modelContext 让任何网站直接向 AI Agent 暴露结构化、可调用的工具。
WebMCP 提供声明式 API（基于现有 HTML 表单）和命令式 API（自定义 JavaScript 逻辑）两种接口。开发团队无需重新架构后端或维护独立的 MCP 服务器，即可将现有客户端逻辑封装为 Agent 可读工具。
💡 INSIGHT
当浏览器层面支持 Agent 交互协议时，AI Agent 从「猜按钮」的游客升级为「直接调用 API」的原住民——这是浏览器自 JavaScript 诞生以来最深刻的范式转变。
