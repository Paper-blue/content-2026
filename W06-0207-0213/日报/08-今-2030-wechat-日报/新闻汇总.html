💡 短评：王慧文三年前组局大模型，这次切 Agent——节奏踩的是应用层成熟度窗口。OpenClaw 的本地执行模式解决了 Manus 云端方案的隐私和延迟问题，但"不设限"的架构也意味着安全边界模糊。各厂商跟进速度说明 Agent Infra 赛道的技术壁垒并不高，真正的护城河在场景和数据飞轮。

🔥 神秘模型 Pony Alpha 引外网热议，疑似国产大模型新作

机器之心 · 技术突破

OpenRouter 平台上线匿名模型 Pony Alpha，定位为前沿基础模型，主攻代码编写、Agent 工作流、推理及角色扮演场景。社区实测推理速度达 17 TPS，免费开放使用但会记录用户提示词与生成内容。

技术社区基于推理速度、模型表现和免费策略进行溯源分析，普遍怀疑 Pony Alpha 为国内头部厂商（智谱 GLM 或 MiniMax）的马甲版本，引发关于模型成本结构和 API 经济透明度的广泛讨论。

💡 短评：匿名发布本质是市场试探策略。17 TPS 在自回归架构中对应特定硬件配置范围，通过推理延迟倒推算力规模是技术溯源的常用方法。免费模型的用户数据留存条款暴露了真实商业逻辑——以流量换训练数据的路径在大模型中后期已成主流打法。

🔥 Waymo 联手 DeepMind 打造世界模型：让自动驾驶"脑补"罕见场景

机器之心 · 技术突破

Waymo 基于 Google DeepMind 的 Genie 3 构建了自动驾驶世界模型，可生成照片级真实的 3D 交互环境，模拟龙卷风、路上遇到大象等极端罕见驾驶场景。输出覆盖摄像头和激光雷达双模态数据。

Waymo 已累计完成近 2 亿英里全自动驾驶里程，但在虚拟世界中的模拟里程达数十亿英里。新模型支持自然语言控制仿真场景，工程师可通过文字指令快速修改路况、天气等参数，加速 Robotaxi 向新城市扩展。

💡 短评：自动驾驶的核心瓶颈一直是长尾场景覆盖。Waymo 用世界模型解决的不是"能不能开"的问题，而是"能不能证明安全"的监管问题——合成数据的仿真覆盖率直接决定了进入新城市的审批速度。语言控制仿真参数这个设计降低了测试工程师的门槛，是工程化思路。

📌 ICLR 2026：一行代码解决 LLM 推理过度思考问题

机器之心 · 技术突破

UIUC 团队在 ICLR 2026 发表研究，提出一种极简方案解决 LLM 推理模型的"过度思考"问题——即模型在简单任务上消耗过多推理步骤，导致延迟增加和计算资源浪费。

研究发现，通过在推理过程中插入一行早停判断代码，即可在不损失准确率的前提下显著减少推理 token 数量。该方法无需重新训练模型，可直接应用于现有 CoT 推理框架。

💡 短评：推理模型的"过度思考"本质是 RLHF 训练中奖励信号对长回复的偏好副作用。一行代码就能解决说明问题不在算法层而在工程层——这类 inference-time 优化对降低 API 成本的直接意义可能比模型架构创新更大。

📌 DeepMind 搭建"算力矿场"暴力搜索下一代激活函数

机器之心 · 技术突破

Google DeepMind 利用 AlphaEvolve 框架，以进化搜索策略大规模挖掘可泛化的激活函数。研究采用 LLM 驱动的搜索管线替代人工设计的搜索空间，在 FLOP 约束下对 Python 级别的候选函数进行灵活探索。

此前 DeepMind 曾通过类似方法发现 Swish 激活函数（x·sigmoid(βx)），在 ImageNet 等任务上超越 ReLU。新一轮搜索目标是找到在更深网络和更大规模模型上表现更优的通用激活函数。

💡 短评：用 AI 搜索 AI 的基础组件，这个递归本身就是 meta-learning 的工程化落地。ReLU 统治了十年，如果能找到一个在 Transformer 规模下收敛更快的替代品，收益是全行业级别的——但发现新激活函数容易，让业界迁移才是真正的门槛。

📌 人形机器人预训练与真机微调新范式（ICLR 2026）

机器之心 · 技术突破

通研院团队在 ICLR 2026 提出人形机器人的"预训练 + 真机微调"范式，通过大规模仿真环境预训练行为基础模型，再在真实机器人上进行少量强化学习微调，实现 sim-to-real 的高效迁移。

该方法参考了 LLM 领域的"预训练 + 微调"范式，在全身运动控制（loco-manipulation）任务上取得突破。研究涉及 Vision-Language-Action 统一框架，可从操作视频中无监督学习动作表征。

💡 短评：机器人领域正在复制 NLP 的"大模型 + 微调"路径。关键挑战在于 sim-to-real gap——仿真中学到的策略在真实物理世界的泛化能力。VLA 框架把视觉、语言、动作统一编码的思路和 GPT-4V 的多模态架构异曲同工，方向是对的。

📌 从视频生成迈向通用世界模拟器：世界模型全新视角

机器之心 · 观点评论

机器之心发布综述文章，系统梳理世界模型的技术演进路径：从早期的视频生成模型（Sora、Runway Gen-3）到当前的交互式 3D 世界模拟器（Genie 3、Cosmos），技术范式正在经历根本性转变。

文章指出，通用世界模拟器需要具备四大能力：物理规律理解、多视角一致性、可交互性和长时序推理。当前主流方案分为扩散模型路线和自回归 Token 路线，两者在生成质量和可控性上各有优劣。

💡 短评：世界模型是 LeCun 一直推的"下一代 AI 架构"。从 Sora 的"看起来像"到 Genie 3 的"可以交互"，核心进展不在视觉质量而在物理一致性。自动驾驶、机器人、游戏三个场景正在成为世界模型的实际验证场，谁先跑通商业闭环谁就定义标准。

📌 中国研制出不确定度最高光钟，720 亿年误差不超 1 秒

36氪 · 技术突破

中科院精密测量科学与技术创新研究院成功研制第二代液氮低温钙离子光钟，总系统不确定度达 4.4E-19（千亿亿分之一），相当于连续计时约 720 亿年误差不超过 1 秒，为目前全球报道的不确定度指标最高光钟。
