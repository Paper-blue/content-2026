出门合盖，三秒连回：Mac 远程开发的 frp + Cloudflare 方案

文 / Zayen知蓝

在咖啡馆掏出 iPad，打开终端，三秒后进入家里 Mac 的工作目录。工具链、本地跑的 AI 工作流、环境变量，一个没少。这篇文章讲的就是怎么做到这件事。

一、问题

移动设备和桌面端之间有一道坎。

不是屏幕大小，也不全是键盘手感。真正卡住的地方在于：你的工作流跑不出本机。

拿我自己的情况说——Mac 上搭了一整套内容创作管线：从 Notion 选题库拉取待写主题，Claude Code 配合自定义 skill 生成文章，md2wechat 转换成公众号格式，一键推送到微信草稿箱。图片生成、AI 去痕、小红书适配、新闻日报，全是本地脚本和环境变量串起来的。

桌面上跑得顺畅。一出门，iPad 上只剩一个空壳终端。

Notion 可以网页访问，Claude 可以网页对话，但那些本地部署的 skill、Python 脚本、存在 ~/.zshrc 里的 API Key——全留在家里的 Mac 上。

移动端不是没有生产力。是生产力的根在桌面端

问题就变成了：怎么在外面也能摸到那台 Mac？

二、选型

远程连回家里的电脑，技术上就是内网穿透。Mac 藏在路由器后面，没有公网 IP，外面的设备直接连不进去。需要一个中间人帮忙打通。

方案分两类。

商业服务——cpolar、NATAPP、花生壳。注册即用，有免费额度，但本质是把端口托管给别人的服务器。安全性取决于你对服务商的信任。花生壳是上市公司，有爆破防护和 IP 白名单，相对可控。cpolar 和 NATAPP 都是小团队，功能基础但够用。

开源方案——Tailscale、frp、Cloudflare Tunnel。Tailscale 是虚拟组网方案，会跟现有的网络工具冲突，日常常驻不太现实。Cloudflare Tunnel 安全性最高，SSH 端口完全不暴露在公网，但远程设备也得装 cloudflared 客户端。frp 最朴素，TCP 端口直接转发，任何 SSH 客户端填个 IP 加端口就能连。

最终两个都配了。Cloudflare Tunnel 作为浏览器 SSH 的备用通道，frp 做主力日常连接。

三、前置

在折腾网络之前，先解决一个物理问题：Mac 合盖了还能不能连？

macOS 的电源管理有两个关键设置。sleep——系统多久后进入睡眠；AppleClamshellCausesSleep——合盖是否触发睡眠。

在"系统设置 → 电池 → 选项"里，把"接通电源时防止自动进入睡眠"打开。然后终端检查一下：

pmset -g           # 确认 sleep = 0

ioreg -r -k AppleClamshellState  # 确认 AppleClamshellCausesSleep = No

两个条件都满足，插电合盖就不会断联。

断电是唯一的风险。电池模式下 Mac 会在一分钟内进入睡眠。保持插电是硬前提。

四、Cloudflare Tunnel

Cloudflare Tunnel 的思路是反向的——不是从外面打进来，而是 Mac 主动跟 Cloudflare 的边缘节点建立一条加密隧道。外面的请求通过 Cloudflare 转进来，SSH 端口从来不直接面对公网。

配置不复杂。装 cloudflared，登录，创建隧道，绑个子域名：

brew install cloudflared

cloudflared tunnel login

cloudflared tunnel create macbook-ssh

cloudflared tunnel route dns macbook-ssh ssh.yourdomain.com

写一份配置文件 ~/.cloudflared/config.yml：

tunnel: <你的隧道ID>

credentials-file: ~/.cloudflared/<隧道ID>.json

 

ingress:

  - hostname: ssh.yourdomain.com

    service: ssh://localhost:22

  - service: http_status:404

注册为系统服务后，在 Cloudflare Zero Trust 控制台给域名加一层 Access 策略——只允许你的邮箱通过 OTP 验证，再开启 Browser Rendering 选 SSH。

效果：任何设备打开 https://ssh.yourdomain.com，邮箱验证后直接进入网页终端。不用装客户端。

但也有局限。想用 Termius 这类原生 SSH 客户端连接，对方设备也得装 cloudflared 做代理。Cloudflare Tunnel 的流量不是原始 TCP，而是封装在它自己的协议里，普通 SSH 客户端解不开。

浏览器里用，挺好。但我更想要原生终端的手感。

五、frp

frp 做的事情简单得多：在一台有公网 IP 的服务器上跑 frps（server），Mac 上跑 frpc（client），TCP 端口直接转发。外面的设备连服务器的某个端口，流量被原样送到 Mac 的 22 端口。

任何 SSH 客户端——Termius、PuTTY、系统自带的 ssh 命令——填上 IP 和端口就能连。不需要额外的代理程序。

服务端

我用 OpenClaw 来自动化 VPS 上的部署。把 frps 的安装步骤丢给它，几分钟跑完：下载二进制、写配置、创建 systemd 服务、设置开机自启。手动操作的部分只有一个——去云服务商控制台的安全组里放行端口。

frps 配置很短：

bindPort = 7000

allowPorts = [

  { start = 6000, end = 6010 }

]

auth.method = "token"

auth.token = "<一个随机强密码>"

7000 是 frp 自己的通信端口，6000 用来转发 SSH。token 防止别人往你的 frps 上挂隧道。

客户端

Mac 上装 frpc：

brew install frpc

配置 /opt/homebrew/etc/frp/frpc.toml：

serverAddr = "<你的 VPS IP>"

serverPort = 7000

 

auth.method = "token"

auth.token = "<跟服务端一样的密码>"

 

[[proxies]]

name = "macbook-ssh"

type = "tcp"

localIP = "127.0.0.1"

localPort = 22

remotePort = 6000

启动并设为开机自启：

brew services start frpc

从此，任何地方打开 SSH 客户端，连 <VPS IP>:6000，就是家里的 Mac。

六、延迟

frp 配好后从 Termius 连了进去。能用，但每个按键有大约半秒的延迟。打一个字，等一下才出现。

原因直接：VPS 在新加坡。按键从手边设备发到新加坡，再从新加坡转到国内的 Mac，响应原路返回。中国到新加坡单程 50-80ms，一个来回加上 frp 转发开销，体感 300-500ms。

解法也直接：换一台国内 VPS。

在阿里云上海开了一台轻量服务器，同样用 OpenClaw 部署 frps。改了 Mac 上 frpc 的 serverAddr，重启服务。

延迟立刻从"能用但难受"变成"几乎感觉不到"。国内到国内通常 10-30ms，打字跟本地终端基本没区别。

VPS 的地域选择比配置本身更影响体验。你和 Mac 都在国内，中转服务器选国内节点。

七、加固

frp 把 SSH 端口暴露在了公网上。任何人知道 VPS IP 和端口，就可以尝试连接。

macOS 的 SSH 默认允许密码登录，密码可以被暴力破解。要做两件事。

第一，用 SSH Key 替代密码。

Mac 上生成密钥对（如果还没有的话）：

ssh-keygen -t ed25519

把公钥加入授权列表：

cat ~/.ssh/id_ed25519.pub >> ~/.ssh/authorized_keys

私钥导入到远程设备的 SSH 客户端。Termius 的操作是进入 Keychain → Add Key，粘贴私钥内容。

第二，关闭密码登录。

Mac 上创建一个 SSH 配置文件：

sudo tee /etc/ssh/sshd_config.d/200-no-password.conf << 'EOF'

PasswordAuthentication no

KbdInteractiveAuthentication no

EOF

sudo launchctl kickstart -k system/com.openssh.sshd

这只影响 SSH 远程连接。本地开机密码、解锁屏幕、sudo 走的是 macOS 自己的认证系统，不受影响。

关闭密码登录后，没有私钥的人连 SSH 的门都摸不到。暴力破解直接失效。

八、最终状态

配置清单

Mac 电源 → 插电合盖不睡眠

SSH 服务 → 运行中，仅允许密钥认证

Cloudflare Tunnel → 浏览器 SSH 备用通道

frp 隧道 → 阿里云上海中转，开机自启

默认目录 → SSH 登录自动进入工作目录

出门前把 Mac 合上，插着电。到了咖啡馆，iPad 打开 Termius，三秒连上。ls 一下，文件都在。跑一条 Claude Code 命令，skill、脚本、环境变量全部就绪。
